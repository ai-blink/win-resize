# WindowResizer v0.02.0-preview.5

[English](v0.02.0-preview.5.md) | [한국어](v0.02.0-preview.5.ko.md) | [中文](v0.02.0-preview.5.zh-CN.md) | [日本語](v0.02.0-preview.5.ja.md)

リリース日：2026-09-30

書き直した WPF（.NET 10）デスクトップアプリの第 5 プレビューです。これまでのプレビューと同じく
`next/` 以下のソースからビルドし、パッケージ配布ではありません。配布中の実行ファイルは引き続き
PyQt5 アプリの v0.01.5 です。

## 主な変更

- ログと情報ページ。上半分はアプリが今使っているものを表示します：バージョン、.NET ランタイム、管理者権限で
  動いているか（管理者権限で動くプログラムのウィンドウは、そうでないと移動できません）、実行ファイル、
  プロファイルフォルダー、設定・オーバーレイ・ショートカットのレジストリキー。コピーでテストするとき、
  実際のプロファイルフォルダーや実際のキーに触れていないことをここで確認できます。ボタンでプロファイル
  フォルダーをエクスプローラーで開き、全体をコピーし（不具合報告用）、設定キーのパスをコピーできます。
- 下半分のログは PyQt5 のデバッグウィンドウの代わりです。新しいアプリにはログのフレームワークがないので、
  すでに見えていたものを記録します：ステータスバーに出たすべてのメッセージを時刻付きで、そして処理されない
  エラーを詳細付きで。各行は情報、警告、エラーのいずれかです（保存や適用の失敗、一致するウィンドウがない、
  設定キーに書き込めない、は警告）。すべて表示、警告以上、エラーのみで絞り込み、100〜10000 行を保持し
  （古い行から破棄）、自動スクロールのオンオフ、クリア、表示中の行のクリップボードへのコピー、見出し付きの
  UTF-8 テキストファイルへの書き出しができます。警告行は太字で色が付き、文字でも WARNING、ERROR と書かれる
  ので、色だけに頼りません。
- メニューバー：ツール > ログ（Ctrl+D）とヘルプ > 情報がこのページを開きます（メニューマップの約束）。
  バージョンがハードコードされていた v0.01.5 の英語の情報ボックスはなくなりました。
- 画面上の例外でアプリが終了しなくなりました。ログにエラーとして残り、ステータスバーに表示され、アプリは
  トレイで動き続けます。ほかのスレッドのエラーは、ランタイムがプロセスを終了する前にログに書きます。
- 言語を切り替えると、レベル名と行数の表示も作り直されます。記録済みの行は書かれたときの言語のままです。

## このプレビューにまだないもの

- ログはその実行中のメモリにだけあり、書き出すまでファイルには残りません。
- アプリアイコン、パッケージ化した実行ファイル、Windows の拡大率 100/125/150/200% での確認。
- ダークモードでタイトルバー、スクロールバー、ドロップダウンのスクロールバーがまだ明るいままです。
- サイドバーが英語の「Windows and profiles」ラベルを短縮して表示します。

## 互換性

- プロファイルと設定の形式は変わりません。新しいコマンドラインオプションはありません。

## 検証

- .NET ソリューションのビルド：警告 0 件、エラー 0 件。
- .NET テスト：227 件、すべて成功（Core 99、App 91、Infrastructure 37）：ログ（追加、最大行数、破棄、
  絞り込み、書き出しテキスト）、ページのビューモデル（リアルタイムの行、絞り込み、クリア、表示中の行だけの
  コピー、BOM 付きの書き出し、クリップボード使用中、書き込めないパス）、ステータスバーとログレベルの対応、
  処理されないエラーの項目、情報ページ、バインディングエラーなしで全ページを描画するスモークテスト。
- 一致するウィンドウがないプロファイル 1 件だけを入れたコピーで実行中のアプリで、実際のキー入力と実際の
  保存ダイアログにより：Ctrl+D でページが開いて起動行があり、情報にこのビルドのバージョンとコピーの
  フォルダー、一時レジストリキーが表示され（実際のものではない）、テーマの変更が情報行として、一致する
  ウィンドウがないプロファイルの適用が警告行として現れ、絞り込みで一覧が警告 1 行、空の一覧と案内文、
  すべて表示へと切り替わり、「すべてコピー」が 5 行すべてをクリップボードに入れ（クリップボードの文字列は
  保存して復元）、書き出しが実際の保存ダイアログで BOM 付き UTF-8 ファイルに見出しと行を書き、「プロファイル
  フォルダーを開く」がコピーのフォルダーをエクスプローラーで開き、クリアで一覧が空になり、ヘルプ > 情報が
  ページを開きました。実際のプロファイルファイル、実際の設定キー、実際のスタートアップ一覧は変わりません
  でした。処理されない例外の扱いは、動作中のアプリをわざと落とさず、単体テストで確認しました。
