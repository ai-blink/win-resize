# WindowResizer v0.02.0

[English](v0.02.0.md) | [한국어](v0.02.0.ko.md) | [中文](v0.02.0.zh-CN.md) | [日本語](v0.02.0.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WindowResizer의 첫 정식 릴리스입니다. 배포 실행 파일이 PyQt5 앱(v0.01.5)에서 이 앱으로 바뀝니다.
앱은 .NET 10 WPF이며, .NET 런타임을 품은 자체 완결형 `WindowResizer.exe` 하나(약 72 MB)로 배포합니다.

`WindowResizer.exe`의 SHA-256: `9323D2A52C49C7A96FBD92E64FB6F57EEDDA001ED5E84A698DCC29843497F373`

## 주요 변경

- 사이드바 다섯 페이지: 창과 프로필, 오버레이 버튼, 단축키, 설정, 로그와 정보.
- 프로필: 창 자리 저장(Ctrl+S), 맞는 창 전부에 적용, 창에서 자리 덮어쓰기(되돌리기), 실행 파일 경로·프로세스 이름·
  제목(포함, 일치, 정규식)·결합으로 매칭. 기존 v0.01.5 `profiles.json`을 같은 형식으로 읽고 쓰며, 앱이 모르는
  키는 그대로 보존합니다.
- 위치 잠금: 프로필을 적용한 창이 옮겨지거나 크기가 바뀌면 적용했던 자리로 되돌립니다(프로필의 오차, 이동 시 복원,
  크기 변경 시 복원, 최대 시도 횟수를 따름). 최대화·최소화한 창은 건드리지 않습니다. 관리자 권한 창처럼 옮길 수
  없는 창은 프로필의 최대 시도 뒤 포기하고 상태 줄에 알립니다.
- 마우스 가둠: 프로필 창이 앞에 있는 동안만 마우스를 그 창 안에 가둡니다. 다른 창으로 전환하면 풀리고 돌아오면 다시
  가둡니다. 프로필의 탈출 키(기본 Escape)로 다음 적용까지 풀 수 있습니다.
- 새 창 자동 적용: 앱을 켠 뒤 새로 뜬 창이 자동 적용 프로필과 맞으면 그 프로필의 `apply_delay`, `max_retries`,
  `retry_delay`대로 자동 적용합니다. 프로필이 여럿 맞으면 가장 구체적인 하나만 적용하고, 앱을 켤 때 이미 열려 있던
  창은 건드리지 않습니다. 상태 줄에 "자동 감지 중: 프로필 N개"가 보입니다.
- 오버레이 버튼: 버튼이 프로필과 따로 자기 이름과 복원할 창 위치·크기를 저장하고, 누르면 직전에 쓰던 창을 그 자리로
  옮깁니다. 속성 창(일반, 크기 및 위치, 동작, 외형)에 실제 크기 미리보기가 있고, 자리는 직전 창에서 가져오거나
  캡처 도구처럼 테두리가 나타나는 화면 선택으로 고릅니다. v0.01.5에서 오버레이를 켜 둔 프로필은 첫 실행 때 버튼으로
  한 번 복사됩니다.
- 프로필별 전역 단축키(여러 조합과 동작), 전체 적용 단축키, 항상 위 전환. 다른 프로그램이 쥔 조합은 이유와 함께
  목록에 보입니다.
- 설정: 밝게·어둡게·시스템 따르기 테마(Windows 고대비 지원), 75%~250% 앱 배율, 한국어·영어, Windows 시작 때 자동
  실행, 창 위치 기억.
- 로그 페이지가 모든 상태 문구와 처리되지 않은 오류를 쌓고 복사·내보내기를 지원합니다.
- 중복 실행 방지: Windows 세션에서 한 벌만 실행됩니다(v0.01.5와 같은 뮤텍스라 두 앱은 함께 뜨지 않음). 두 번째
  실행은 아무 일도 안 하는 대신 첫 앱의 창을 앞으로 냅니다.
- 창을 닫으면 트레이에 남고, `Ctrl+Q`나 트레이 메뉴가 종료입니다.

## v0.01.5와 달라진 점

- 다른 창으로 전환하면 마우스 가둠이 풀립니다(v0.01.5는 해제 단축키를 누를 때까지 유지).
- 프로필의 탈출 키가 동작합니다(v0.01.5는 저장만 하고 무시).
- 잠금은 프로필 값이 아니라 옮긴 뒤 창의 실제 자리로 되돌립니다. 최소 크기가 있는 창이 잠금과 영원히 싸우지 않습니다.
- 새 창 자동 적용이 프로필별 지연·재시도 설정을 따르고(v0.01.5는 고정값), 별도 시작 버튼 없이 자동 적용이 켜진
  프로필이 하나라도 있는 동안 동작합니다.
- 오버레이 버튼이 프로필과 분리되었고 "모두 닫기"는 "모든 버튼 감추기"가 되었습니다.

## 이번 릴리스에 없는 것

- v0.01.5의 3초 프로필 미리보기 테두리.
- 앱 표시 언어의 중국어·일본어(한국어와 영어만. 문서는 4개 언어).
- 설치 프로그램과 업데이트 방식.
- 오버레이 버튼의 화면 위 편집 모드(끌어서 옮기기, 크기 손잡이)와 "지금 창의 위치로 덮어쓰기"의 되돌리기.
- 프로필 편집 창에 "오버레이 버튼 사용"이 아직 있으며 더 이상 버튼을 만들지 않습니다.

## 호환성

- 프로필 파일은 v0.01.5 형식을 유지합니다. 설정은 `HKCU\Software\WindowResizer\Next`에 저장하며, v0.01.5의 테마·앱 배율·
  오버레이 설정은 첫 실행에서 한 번 읽기만 하고 되쓰지 않습니다.
- Windows 10 또는 11, 64비트. 관리자 권한 창은 일반 권한 WindowResizer로 조작할 수 없으니 필요하면 같은 권한으로
  실행하세요.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개. 테스트 281개 통과(Core 127, App 114, Infrastructure 40, 포커스에 의존하는
  라이브 테스트 1개는 건너뛸 수 있음). 모든 페이지와 창을 그려 바인딩 오류 0건을 확인하는 렌더 스모크, 잠금·마우스
  가둠·자동 적용 감시의 가짜 창 테스트를 포함합니다.
- 실제 프로필 사본과 임시 레지스트리 키로 UI Automation 을 써서 확인: 오버레이 버튼(프로필에서 복사, 새 버튼, 속성 창,
  실제 크기 미리보기, 화면 선택 테두리와 Esc), 두 번째 실행이 첫 앱에 신호를 보내는 것, 실제 `profiles.json`이 바뀌지
  않는 것.
- 실제 마우스 클릭으로 확인하지 못한 것: 오버레이 버튼 우클릭 메뉴와 화면 선택으로 창을 고르는 클릭. 잠금, 마우스 가둠,
  자동 적용 감시는 이번 릴리스 과정에서 실제 프로그램이 아니라 가짜 창 테스트와 연결 확인으로 검증했습니다. 이상한 점이
  있으면 알려 주세요.
