# WindowResizer v0.02.0-preview.7

[English](v0.02.0-preview.7.md) | [한국어](v0.02.0-preview.7.ko.md) | [中文](v0.02.0-preview.7.zh-CN.md) | [日本語](v0.02.0-preview.7.ja.md)

发布日期：2026-09-30

重写的 WPF（.NET 10）桌面应用的第七个预览版，从 `next/` 下的源码构建；分发的可执行文件仍是
PyQt5 应用 v0.01.5。本预览改进了悬浮按钮的右键菜单。

## 主要变更

- 悬浮按钮的右键菜单现在会说明该按钮对应什么。从上到下：配置文件名称（粗体，不可点击）；配置文件匹配的
  目标（可执行文件名和完整路径，或窗口标题、进程名模式，以及匹配方式）；已保存的位置和大小；
  “编辑此配置文件...”；“关闭此按钮”。
- “编辑此配置文件...”无论主窗口选中了哪个配置文件，都会直接打开该配置文件的编辑窗口，保存走与在
  配置文件列表中编辑相同的路径。
- “关闭此按钮”保持不变：只关闭该配置文件的悬浮按钮。

## 本预览尚未包含

- 按钮的工具提示没有变化。
- Windows 100/125/150/200% 缩放检查仍未验证。
- 安装程序或更新机制，以及替换 v0.01.5 可执行文件。

## 兼容性

- 配置文件和设置格式没有变化。没有新的命令行选项。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：233 个，全部通过（Core 99、App 97、Infrastructure 37）。新测试覆盖每种匹配方式的菜单行、
  按 id 编辑配置文件（其他配置文件不受影响，未知 id 不会打开任何窗口），以及打开菜单并点击两个项目的
  渲染冒烟测试。
- 未能验证对运行中的悬浮按钮进行真实鼠标右键：电脑正在使用，光标一直在移动，通过窗口消息发送的点击也
  没有打开菜单。
