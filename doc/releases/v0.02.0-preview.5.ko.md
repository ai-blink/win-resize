# WindowResizer v0.02.0-preview.5

[English](v0.02.0-preview.5.md) | [한국어](v0.02.0-preview.5.ko.md) | [中文](v0.02.0-preview.5.zh-CN.md) | [日本語](v0.02.0-preview.5.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WPF(.NET 10) 데스크톱 앱의 다섯 번째 미리보기입니다. 앞선 미리보기와 같이
`next/` 아래 소스에서 빌드하며 패키지로 배포하지 않습니다. 배포 실행 파일은 계속
PyQt5 앱 v0.01.5 입니다.

## 주요 변경

- 로그와 정보 페이지. 위쪽은 앱이 지금 쓰는 것을 보여 줍니다: 버전, .NET 런타임, 관리자
  권한 여부(관리자 권한으로 뜬 프로그램의 창은 그렇지 않으면 옮길 수 없습니다), 실행 파일,
  프로필 폴더, 설정·오버레이·단축키의 레지스트리 키. 사본으로 시험할 때 실제 프로필 폴더와
  실제 키를 건드리지 않는지 여기서 눈으로 확인할 수 있습니다. 버튼으로 프로필 폴더를 탐색기에서
  열고, 전체를 복사하고(버그를 알릴 때), 설정 키 경로를 복사합니다.
- 아래쪽 로그는 PyQt5 디버그 창을 대신합니다. 새 앱에는 로깅 프레임워크가 없어서, 이미 보이던
  것을 기록합니다: 상태 줄에 뜬 모든 문구를 시각과 함께, 그리고 잡히지 않은 오류를 전체 내용과
  함께. 줄마다 정보, 경고, 오류가 있습니다(저장이나 적용 실패, 맞는 창 없음, 설정 키 쓰기 실패는
  경고). 전부 보기, 경고 이상, 오류만으로 걸러 보고, 100~10000줄을 두고(오래된 줄부터 버림),
  자동 스크롤을 켜고 끄고, 지우고, 보이는 줄을 클립보드에 복사하고, 머리말이 붙은 UTF-8 텍스트
  파일로 내보냅니다. 경고 줄은 굵고 색이 있으며 글자로도 WARNING, ERROR 라고 적혀 색에만 기대지
  않습니다.
- 메뉴 막대: 도구 > 로그(Ctrl+D)와 도움말 > 정보가 이 페이지를 엽니다(메뉴 지도의 약속). 버전이
  하드코딩된 v0.01.5 의 영어 정보 상자는 없어졌습니다.
- 화면의 예외가 더 이상 앱을 끝내지 않습니다. 로그에 오류로 남고 상태 줄에 보이며 앱은 트레이에서
  계속 돕니다. 다른 스레드의 오류는 런타임이 프로세스를 끝내기 전에 로그에 적습니다.
- 언어를 바꾸면 수준 이름과 개수 문구도 다시 만들어집니다. 이미 기록된 줄은 쓰일 때의 언어 그대로입니다.

## 이 미리보기에 아직 없는 것

- 로그는 그 실행 동안 메모리에만 있고, 내보내기 전에는 파일로 남지 않습니다.
- 앱 아이콘, 패키지 실행 파일, Windows 배율 100/125/150/200% 확인.
- 다크 모드에서 제목 줄, 스크롤바, 드롭다운 스크롤바가 아직 밝습니다.
- 사이드바가 영어 "Windows and profiles" 이름을 줄여 보입니다.

## 호환성

- 프로필과 설정 형식은 바뀌지 않습니다. 새 명령줄 옵션은 없습니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 227개, 모두 통과했습니다(Core 99, App 91, Infrastructure 37): 로그(쌓기, 최대
  줄 수, 버리기, 걸러 보기, 내보내기 본문), 페이지 뷰모델(실시간 줄, 걸러 보기, 지우기, 보이는
  줄만 복사, BOM 붙인 내보내기, 클립보드 사용 중, 쓸 수 없는 경로), 상태 줄과 로그 수준의 대응,
  잡히지 않은 오류 항목, 정보 페이지, 바인딩 오류 없이 모든 페이지를 그려 보는 스모크.
- 맞는 창이 없는 프로필 하나만 담은 사본으로 실행 중인 앱에서 실제 키 입력과 실제 저장 대화상자로:
  Ctrl+D 가 페이지를 열고 시작 줄이 있었고, 정보에 이 빌드의 버전과 사본 폴더, 임시 레지스트리
  키가 보였고(실제 것이 아님), 테마 변경이 정보 줄로, 맞는 창이 없는 프로필 적용이 경고 줄로
  나타났고, 걸러 보기가 목록을 경고 한 줄로, 빈 목록과 안내 문구로, 다시 전체로 바꿨고, 전체 복사가
  다섯 줄 모두를 클립보드에 넣었고(클립보드 글은 저장했다 되돌림), 내보내기가 실제 저장 대화상자로
  BOM 이 붙은 UTF-8 파일에 머리말과 줄을 썼고, 프로필 폴더 열기가 사본 폴더를 탐색기로 열었고,
  지우기가 목록을 비웠고, 도움말 > 정보가 페이지를 열었습니다. 실제 프로필 파일, 실제 설정 키,
  실제 시작 목록은 바뀌지 않았습니다. 잡히지 않은 예외 처리는 실행 중인 앱을 일부러 죽여 보지 않고
  단위 테스트로 확인했습니다.
