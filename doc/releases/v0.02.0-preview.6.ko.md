# WindowResizer v0.02.0-preview.6

[English](v0.02.0-preview.6.md) | [한국어](v0.02.0-preview.6.ko.md) | [中文](v0.02.0-preview.6.zh-CN.md) | [日本語](v0.02.0-preview.6.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WPF(.NET 10) 데스크톱 앱의 여섯 번째 미리보기입니다. 앞선 미리보기와 같이
`next/` 아래 소스에서 빌드하며, 배포 실행 파일은 계속 PyQt5 앱 v0.01.5 입니다. 이번에는 앱
아이콘과 단일 파일 exe 를 만드는 방법이 들어갔습니다.

## 주요 변경

- 앱 아이콘. 저장소에 이미 있던 3D 창 아이콘(회색 창, 색 점 세 개, 크기 조절 화살표)을 이제
  모든 곳에 씁니다: 탐색기의 exe, 창 제목줄(메인, 프로필 편집, 창 고르기), 작업 표시줄, 트레이.
  옛 원본은 256 px 한 장이라 Windows 가 줄이면 회색 덩어리가 되므로, 아이콘 파일이 아홉 크기(16, 20,
  24, 32, 40, 48, 64, 128, 256 px)를 담고 Windows 가 맞는 것을 고릅니다.
  `next/tools/make_app_icon.py` 가 원본 PNG 에서 이 파일을 다시 만듭니다.
- 단일 파일 빌드. `next/tools/publish.ps1` 이 자기 .NET 런타임을 품은 self-contained 단일 파일
  exe(`next/publish/win-x64/WindowResizer.App.exe`, 압축 72.3 MB)를 만듭니다. .NET 이 없는 PC 에서도
  뜹니다. 시험 PC 에서 첫 실행은 3.4초(네이티브 라이브러리를 `%TEMP%\.net` 에 푸는 시간), 이후 실행은
  1.6초였습니다. 이 파일은 배포하지 않으며 v0.01.5 실행 파일을 대체하지 않습니다.
- 파일 버전이 다시 프리뷰 번호를 따릅니다(`0.2.0.6`, 그동안 `.3` 에 머물러 있었습니다).

## 이 미리보기에 아직 없는 것

- Windows 배율 100/125/150/200% 확인은 요청으로 건너뛰었고 검증하지 않았습니다.
- 설치 프로그램이나 업데이트 방식, v0.01.5 실행 파일의 교체.
- 다크 모드에서 제목 줄, 스크롤바, 드롭다운 스크롤바가 아직 밝습니다.
- 아이콘은 기존 그림을 줄인 것이라 16 px 에서는 색 점이 있는 작은 회색 창으로 보입니다.

## 호환성

- 프로필과 설정 형식은 바뀌지 않습니다. 새 명령줄 옵션은 없습니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 227개, 모두 통과했습니다(Core 99, App 91, Infrastructure 37). 렌더 스모크가 아이콘
  파일에 아홉 크기가 다 있는지, 트레이가 맞는 프레임(16, 32 px)을 고르는지, 메인·편집·창 고르기 창이
  아이콘을 갖는지도 봅니다.
- 게시한 exe 를 프로필 사본과 임시 레지스트리 키로 실행: 게시 폴더에는 그 파일 하나뿐이고, 버전 리소스가
  `0.02.0-preview.6` 이고, 탐색기에서 exe 가 앱 아이콘을 보이고, 창이 열리고, 설치된 .NET 에서 불러온
  모듈이 없이 스스로 푼 네이티브 라이브러리만 쓰고, 캡처로 창 제목줄과 작업 표시줄 버튼에 아이콘이
  보이며, Windows 가 남긴 트레이 아이콘 스냅샷이 같은 그림입니다. 실제 프로필 파일, 실제 설정 키,
  v0.01.5 실행 파일은 바뀌지 않았습니다.
