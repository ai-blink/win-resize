# WindowResizer v0.02.0-preview.6

[English](v0.02.0-preview.6.md) | [한국어](v0.02.0-preview.6.ko.md) | [中文](v0.02.0-preview.6.zh-CN.md) | [日本語](v0.02.0-preview.6.ja.md)

リリース日：2026-09-30

書き直した WPF（.NET 10）デスクトップアプリの第 6 プレビューです。これまでのプレビューと同じく `next/`
以下のソースからビルドします。配布中の実行ファイルは引き続き PyQt5 アプリの v0.01.5 です。今回はアプリ
アイコンと、単一ファイルの exe を作る方法が加わりました。

## 主な変更

- アプリアイコン。リポジトリにすでにあった 3D のウィンドウアイコン（灰色のウィンドウ、色付きの点 3 つ、
  サイズ変更の矢印）を、エクスプローラーの exe、ウィンドウのタイトルバー（メイン、プロファイル編集、
  ウィンドウ選択）、タスクバー、トレイのすべてで使うようにしました。以前の元画像は 256 px の 1 枚だけで、
  Windows が縮小すると灰色のかたまりになるため、アイコンファイルに 9 つのサイズ（16、20、24、32、40、48、
  64、128、256 px）を入れ、Windows が合うものを選びます。`next/tools/make_app_icon.py` が元の PNG から
  このファイルを作り直します。
- 単一ファイルのビルド。`next/tools/publish.ps1` が、自前の .NET ランタイムを含む self-contained 単一ファイル
  exe（`next/publish/win-x64/WindowResizer.App.exe`、圧縮後 72.3 MB）を作ります。.NET が入っていない PC でも
  起動します。テスト PC では初回起動が 3.4 秒（ネイティブライブラリーを `%TEMP%\.net` に展開する時間）、
  以降は 1.6 秒でした。このファイルは配布せず、v0.01.5 の実行ファイルも置き換えません。
- ファイルバージョンがプレビュー番号に再び追従します（`0.2.0.6`、これまで `.3` のままでした）。

## このプレビューにまだないもの

- Windows の拡大率 100/125/150/200% での確認は依頼によりスキップしており、検証していません。
- インストーラーや更新の仕組み、v0.01.5 の実行ファイルの置き換え。
- ダークモードでタイトルバー、スクロールバー、ドロップダウンのスクロールバーがまだ明るいままです。
- アイコンは既存の絵を縮小したもので、16 px では色付きの点がある小さな灰色のウィンドウに見えます。

## 互換性

- プロファイルと設定の形式は変わりません。新しいコマンドラインオプションはありません。

## 検証

- .NET ソリューションのビルド：警告 0 件、エラー 0 件。
- .NET テスト：227 件、すべて成功（Core 99、App 91、Infrastructure 37）。描画のスモークテストは、アイコン
  ファイルに 9 つのサイズがそろっていること、トレイが合うフレーム（16 と 32 px）を選ぶこと、メイン・編集・
  ウィンドウ選択の各ウィンドウがアイコンを持つことも確認します。
- 公開した exe を、プロファイルのコピーと一時レジストリキーで実行：公開フォルダーにはそのファイル 1 つだけ、
  バージョンリソースは `0.02.0-preview.6`、エクスプローラーで exe にアプリアイコンが表示され、ウィンドウが
  開き、インストール済みの .NET から読み込まれたモジュールはなく自分で展開したネイティブライブラリーだけを
  使い、スクリーンショットでウィンドウのタイトルバーとタスクバーのボタンにアイコンが表示され、Windows が
  保存したトレイアイコンのスナップショットも同じ絵でした。実際のプロファイルファイル、実際の設定キー、
  v0.01.5 の実行ファイルは変わりませんでした。
