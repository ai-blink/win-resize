# WindowResizer v0.02.0

[English](v0.02.0.md) | [한국어](v0.02.0.ko.md) | [中文](v0.02.0.zh-CN.md) | [日本語](v0.02.0.ja.md)

リリース日: 2026-09-30

書き直した WindowResizer の最初の正式リリースです。配布される実行ファイルが PyQt5 アプリ（v0.01.5）からこのアプリに変わります。
アプリは .NET 10 の WPF で、.NET ランタイムを内蔵した自己完結型の `WindowResizer.exe` 1 つ（約 72 MB）として配布します。

`WindowResizer.exe` の SHA-256: `9323D2A52C49C7A96FBD92E64FB6F57EEDDA001ED5E84A698DCC29843497F373`

## 主な変更

- サイドバー付きの 5 ページ: ウィンドウとプロファイル、オーバーレイボタン、ショートカット、設定、ログと情報。
- プロファイル: ウィンドウの位置の保存（Ctrl+S）、一致する全ウィンドウへの適用、ウィンドウからの位置の上書き（元に戻せます）、
  実行ファイルのパス・プロセス名・タイトル（含む、完全一致、正規表現）・組み合わせでの照合。既存の v0.01.5 の
  `profiles.json` を同じ形式で読み書きし、アプリが知らないキーは保持します。
- 位置ロック: プロファイルのウィンドウが動かされたりサイズ変更されたりしたら、適用時の位置へ戻します（プロファイルの許容差、
  移動時の復元、サイズ変更時の復元、最大試行回数に従います）。最大化・最小化されたウィンドウには触れません。管理者権限の
  ウィンドウのように動かせないものは、プロファイルの最大試行回数の後に諦めてステータスバーに知らせます。
- マウスの閉じ込め: プロファイルのウィンドウが前面にある間だけ、マウスをそのウィンドウ内に閉じ込めます。他のウィンドウへ
  切り替えると解除され、戻ると再び閉じ込めます。プロファイルの脱出キー（既定は Escape）で、次に適用するまで解除できます。
- 新しいウィンドウの自動適用: アプリ起動後に現れ、自動適用プロファイルに合うウィンドウへ、そのプロファイルの `apply_delay`、
  `max_retries`、`retry_delay` に従って自動適用します。複数のプロファイルが合う場合は最も具体的な 1 つだけを適用し、起動時に
  すでに開いていたウィンドウには触れません。ステータスバーに「新しいウィンドウを監視中: プロファイル N 個」と表示されます。
- オーバーレイボタン: 各ボタンがプロファイルとは別に、自分の名前と復元するウィンドウの位置・サイズを保存し、押すと直前に
  使っていたウィンドウをそこへ移動します。プロパティ画面（全般、サイズと位置、動作、外観）に実寸プレビューがあり、位置は
  直前のウィンドウから取得するか、キャプチャツールのように枠が出る画面上の選択で指定します。v0.01.5 でオーバーレイを有効に
  していたプロファイルは、初回起動時に一度だけボタンへコピーされます。
- プロファイルごとのグローバルショートカット（複数の組み合わせと動作）、全適用ショートカット、常に手前の切り替え。他のプログラムが
  使っている組み合わせは理由付きで一覧に表示されます。
- 設定: ライト、ダーク、システム追従のテーマ（Windows ハイコントラスト対応）、75%〜250% のアプリ倍率、韓国語または英語、
  Windows 起動時の自動実行、ウィンドウ位置の記憶。
- ログページが全てのステータスメッセージと未処理のエラーを記録し、コピーやエクスポートができます。
- 多重起動の防止: Windows セッションで 1 つだけ起動します（v0.01.5 と同じミューテックスなので、2 つのアプリは同時に起動しません）。
  2 回目の起動は何も起きない代わりに、最初のウィンドウを前面に出します。
- ウィンドウを閉じるとトレイに常駐し、Ctrl+Q かトレイメニューで終了します。

## v0.01.5 からの変更点

- 他のウィンドウへ切り替えると、マウスの閉じ込めは解除されます（v0.01.5 は解除ショートカットを押すまで保持）。
- プロファイルの脱出キーが動作します（v0.01.5 は保存するだけで無視）。
- ロックは、プロファイルの値ではなく移動後のウィンドウの実際の位置へ戻します。最小サイズを持つウィンドウがロックと永遠に争いません。
- 新しいウィンドウの自動適用はプロファイルごとの遅延と再試行の設定に従い（v0.01.5 は固定値）、別の開始ボタンなしで、自動適用を
  有効にしたプロファイルが 1 つでもある間は動作します。
- オーバーレイボタンはプロファイルから分離され、「すべて閉じる」は「すべてのボタンを隠す」になりました。

## このリリースにまだ無いもの

- v0.01.5 の 3 秒間のプロファイルプレビュー枠。
- アプリ表示の中国語と日本語（韓国語と英語のみ。ドキュメントは 4 言語）。
- インストーラーと更新の仕組み。
- オーバーレイボタンの画面上での編集モード（ドラッグ、サイズ変更ハンドル）と、「現在のウィンドウの位置で上書き」の元に戻す機能。
- プロファイル編集画面に「オーバーレイボタンを使う」が残っています。ボタンは作らなくなりました。

## 互換性

- プロファイルファイルは v0.01.5 の形式を保ちます。設定は `HKCU\Software\WindowResizer\Next` に保存し、v0.01.5 のテーマ・アプリ倍率・
  オーバーレイ設定は初回起動時に一度だけ読み込み、書き戻しません。
- Windows 10 または 11、64 ビット。管理者権限のウィンドウは標準権限の WindowResizer では操作できないため、必要なら同じ権限で実行してください。

## 検証

- .NET ソリューションのビルド: 警告 0 件、エラー 0 件。テスト 281 件が成功（Core 127、App 114、Infrastructure 40。フォーカスに依存する
  ライブテスト 1 件はスキップされることがあります）。全ページとウィンドウを描画してバインディングエラー 0 件を確認するレンダリング
  スモークと、ロック・マウスの閉じ込め・自動適用の監視の模擬ウィンドウテストを含みます。
- 実際のプロファイルのコピーと一時的なレジストリキーを使い、UI Automation で確認: オーバーレイボタン（プロファイルからのコピー、新しい
  ボタン、プロパティ画面、実寸プレビュー、画面上の選択枠と Esc）、2 回目の起動が最初のアプリへ信号を送ること、実際の `profiles.json` が
  変わらないこと。
- 実際のマウスクリックでは確認していないこと: オーバーレイボタンの右クリックメニューと、画面上の選択でウィンドウを選ぶクリック。
  ロック、マウスの閉じ込め、自動適用の監視は、今回のリリース作業では実際のプログラムではなく模擬ウィンドウのテストと接続の確認で検証しました。
  おかしな点があればお知らせください。
