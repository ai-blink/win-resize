# WindowResizer v0.02.0-preview.7

[English](v0.02.0-preview.7.md) | [한국어](v0.02.0-preview.7.ko.md) | [中文](v0.02.0-preview.7.zh-CN.md) | [日本語](v0.02.0-preview.7.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WPF(.NET 10) 데스크톱 앱의 일곱 번째 미리보기입니다. `next/` 아래 소스에서 빌드하며,
배포 실행 파일은 계속 PyQt5 앱 v0.01.5 입니다. 이번에는 오버레이 버튼의 우클릭 메뉴를 고쳤습니다.

## 주요 변경

- 오버레이 버튼 우클릭 메뉴가 그 버튼이 무엇에 연결됐는지 보여 줍니다. 위에서부터: 프로필 이름(굵게,
  누를 수 없음), 프로필이 맞추는 대상(실행 파일 이름과 전체 경로, 또는 창 제목·프로세스 이름 패턴과
  매칭 방식), 저장된 위치와 크기, "이 프로필 편집...", "이 버튼 닫기".
- "이 프로필 편집..." 은 메인 창에서 어느 프로필이 선택돼 있든 그 프로필의 편집 창을 바로 열고,
  저장은 프로필 목록에서 편집할 때와 같은 경로를 탑니다.
- "이 버튼 닫기" 는 그대로입니다. 그 프로필의 오버레이 사용 여부만 끕니다.

## 이 미리보기에 아직 없는 것

- 버튼의 툴팁은 바뀌지 않았습니다.
- Windows 배율 100/125/150/200% 확인은 아직 검증하지 않았습니다.
- 설치 프로그램이나 업데이트 방식, v0.01.5 실행 파일의 교체.

## 호환성

- 프로필과 설정 형식은 바뀌지 않습니다. 새 명령줄 옵션은 없습니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 233개, 모두 통과했습니다(Core 99, App 97, Infrastructure 37). 새 테스트는 모든 매칭
  방식의 메뉴 줄, id 로 프로필 편집(다른 프로필은 그대로, 없는 id 는 아무것도 열지 않음), 메뉴를 열고 두
  항목을 누르는 렌더 스모크를 다룹니다.
- 실행 중인 오버레이 버튼에 실제 마우스 우클릭을 하는 검증은 하지 못했습니다. PC 를 쓰는 중이라 커서가
  계속 움직였고, 창 메시지로 보낸 클릭으로는 메뉴가 열리지 않았습니다.
