# WindowResizer v0.02.0-preview.4

[English](v0.02.0-preview.4.md) | [한국어](v0.02.0-preview.4.ko.md) | [中文](v0.02.0-preview.4.zh-CN.md) | [日本語](v0.02.0-preview.4.ja.md)

リリース日：2026-09-30

書き直した WPF（.NET 10）デスクトップアプリの第 4 プレビューです。これまでのプレビューと同じく
`next/` 以下のソースからビルドし、パッケージ配布ではありません。配布中の実行ファイルは引き続き
PyQt5 アプリの v0.01.5 です。

## 主な変更

- 設定ページ。テーマ（ライト、ダーク、システムに合わせる）、表示サイズ、言語、Windows 起動時の自動実行、
  ウィンドウのサイズと位置の記憶。変更はすぐに保存・反映され、再起動は不要です。
- テーマ。「システムに合わせる」は、アプリの実行中に Windows のアプリモードに追従します。Windows の
  ハイコントラストがオンのときは、何を選んでいても常にその色を使います。
- 表示サイズは 75% から 125% まで 5% 刻みです（既定は 100%）。文字、余白、コントロールが一緒に大きくなり、
  ウィンドウも一緒に大きくなります。スライダーをドラッグしている間は横の数字だけが変わり、
  放したときに適用されます。ドラッグ中の適用も試して実測しましたが、スライダー自体がサイズと一緒に拡大縮小して
  カーソルから逃げ、値が 2 つの刻みの間を行き来しました。キー操作と
  トラックのクリックは即時に適用されます。リセットボタンで 100% に戻ります。
- 言語は韓国語と英語で、ウィンドウを開き直さずに切り替わります。画面、メニュー、トレイメニュー、
  ショートカット一覧まで切り替わります。
- Windows 起動時の自動実行は、現在のユーザーのスタートアップ項目を追加し（管理者権限は不要）、
  ウィンドウを開かずトレイのみで起動します（`--minimized`）。チェックボックスは自前のコピーではなく、
  Windows に登録されている状態を表示します。
- ウィンドウのサイズと位置の記憶。メイン ウィンドウは前回の場所で開きます。すべてのモニターの外にある
  位置（モニターを外した、解像度が変わった）は画面内に戻され、最小サイズより小さくは開きません。
- 初回起動時に v0.01.5 の設定からテーマと表示サイズを取り込み（テスト PC ではシステムに合わせる、75%）、
  `HKCU\Software\WindowResizer\Next\Settings` に別途保存します。v0.01.5 のキーには書き込みません。
  v0.01.5 のウィンドウのサイズと位置は取り込みません。Qt の論理ピクセルであり、旧ウィンドウ（920x640）が
  このアプリの最小サイズより小さいためです。「ハイコントラスト」配色はシステムに合わせるに対応させます
  （Windows のハイコントラストをオンにするとその色になります）。

## このプレビューにまだないもの

- ログと情報ページ、アプリアイコン、パッケージ化した実行ファイル。
- Windows の拡大率 100/125/150/200% での表示サイズの確認（Windows の拡大率を手動で変える必要があります）。
- ダークモードでタイトルバー、スクロールバー、ドロップダウンのスクロールバーがまだ明るいままです。
- ユーザー定義の配色（v0.01.5 の JSON テーマファイル）には対応していません。

## 互換性

- `--settings-key <レジストリのパス>` は設定を別のキーに置き（取り込みも省略します）、
  `--run-key <レジストリのパス>` はスタートアップ項目を別の Run キーに置きます（テスト用）。
  `--minimized` はトレイのみで起動します。

## 検証

- .NET ソリューションのビルド：警告 0 件、エラー 0 件。
- .NET テスト：201 件、すべて成功（Core 89、App 75、Infrastructure 37）：値の規則、初回のみの取り込み
  （v0.01.5 が書き込む DWORD の倍率値を含む）、ウィンドウ位置の補正、ドラッグ中の規則、スタートアップ項目、
  125% で設定ページを描画するスモークテスト。
- プロファイルのコピーと一時レジストリキーで実行中のアプリで、実際のキー入力と実際のマウスドラッグにより：
  各テーマカードで色がすぐに変わり保存され、システムに合わせるは Windows と一致し、矢印キーでサイズが
  変わり（ウィンドウが 10% 拡大）、スライダーのドラッグ中は何も変わらず、放すと適用・保存され、リセットで
  100% に戻り、言語の切り替えでサイドバーの文字が両方向に切り替わり、スタートアップのチェックボックスは
  `--minimized` で終わる引用符付きコマンドを書き込み、削除し、トレイに閉じたウィンドウは位置を保存して
  同じ位置とサイズ（3 px 以内）で開き直り、記憶をオフにすると保存値が削除され、画面のはるか外に保存された
  位置は画面内で開き、`--minimized` はウィンドウなしでプロセスを維持しました。実際のプロファイルファイル、
  実際の設定キー、実際のスタートアップ一覧は変わりませんでした。
