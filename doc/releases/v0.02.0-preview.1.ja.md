# WindowResizer v0.02.0-preview.1

[English](v0.02.0-preview.1.md) | [한국어](v0.02.0-preview.1.ko.md) | [中文](v0.02.0-preview.1.zh-CN.md) | [日本語](v0.02.0-preview.1.ja.md)

リリース日: 2026-09-27

書き直した WPF（.NET 10）デスクトップアプリの最初のプレビューです。`next/` 以下の
ソースからビルドし、パッケージとしては配布しません。配布される実行ファイルは引き続き
PyQt5 アプリ v0.01.5 です。

## 主な変更

- 左サイドバー付きの新しいメインウィンドウ。ウィンドウ一覧とプロファイルが並び、
  Ctrl+F で検索、Enter はウィンドウを再走査してから選択したプロファイルを一致する
  すべてのウィンドウに適用します。
- ウィンドウからプロファイルを作成: 「新しいプロファイルとして保存」（Ctrl+S）は、選択
  したウィンドウの位置とプログラム名（重複時は番号付き）を入れた編集画面を開きます。
  「位置を上書き」はウィンドウの位置でプロファイルを更新し、ステータスバーで元に戻せます
  （Ctrl+Z）。
- 5 ページのサイドバー編集画面: 一般、対象ウィンドウ、位置とサイズ、実行方法、詳細。
  コピーを編集し、保存前に入力を確認し、表示しない項目も保持します。「現在のウィンドウ
  から取得」は一致するウィンドウが複数あると選択させます。
- 最大化・最小化されたウィンドウは通常の位置で取得します。最小化ウィンドウの -32000
  座標は保存しません。
- より安全なプロファイルファイル: 保存に失敗すると変更を元に戻します。読めない
  プロファイルは捨てずにファイルに残し、一覧に薄く表示します。ファイル全体が読めない
  場合は読み取り専用で開きます。
- ウィンドウを閉じるとトレイに隠れます。プログラム終了（サイドバー下部、Ctrl+Q、トレイ
  メニュー）で実際に終了します。v0.01.5 ではメニューの「終了」は隠すだけでした。
- オーバーレイ設定ページ、オーバーレイメニュー、トレイ項目: クリック/ドウェル、
  ドウェル時間、非表示、非表示スイッチ、位置ロック、プロファイルごとのボタン、すべて閉じる。
- 韓国語と英語の画面。システムのライト/ダークテーマに従います。

## このプレビューにまだないもの

- オーバーレイボタンのウィンドウと非表示スイッチ（設定はすでに保存されます）。
- ショートカットページ、設定ページ（テーマ、UI サイズ、言語）、ログと情報ページ。
- アプリアイコンとパッケージ化された実行ファイル。

## 互換性

- プロファイルは同じ `profiles.json` 形式で、プレビューが書いたファイルを PyQt5 が
  読めます。プレビューは渡されたフォルダー（`--profiles-dir`）に書き込むため、
  プロファイルフォルダーのコピーで試してください。
- オーバーレイ設定は別のレジストリキー `HKCU\Software\WindowResizer\Next\Overlay` に
  物理ピクセルで保存します。初回起動時に v0.01.5 のクリック/ドウェル、ドウェル時間、
  非表示、スイッチ、ロックの値を取り込みます。旧座標は単位が異なるため、ボタン位置は
  新しく始まります。

## 検証

- .NET ソリューションのビルド: 警告 0 件、エラー 0 件。
- .NET テスト: 102 件合格。実際のメモ帳ウィンドウ（適用、4 状態での取得）、実際の
  キー入力、カーソル制限、前面ウィンドウ追跡、バインドエラー 0 件の画面描画のライブ
  確認を含みます。
- 実行中のアプリで: ウィンドウを閉じるとプロセスはトレイに残り、サイドバーの
  プログラム終了ボタンで終了します。
