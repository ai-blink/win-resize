# WindowResizer v0.02.0-preview.9

[English](v0.02.0-preview.9.md) | [한국어](v0.02.0-preview.9.ko.md) | [中文](v0.02.0-preview.9.zh-CN.md) | [日本語](v0.02.0-preview.9.ja.md)

Release date: 2026-09-30

Ninth preview of the rewritten WPF (.NET 10) desktop app, built from source under `next/`;
the distributed executable is still the PyQt5 app, v0.01.5. This preview adds an actual-size
preview to the overlay button properties window.

## Highlights

- The Look page of the button properties window shows a preview of the button at its real
  on-screen size. It is drawn by the same code as the real button, and it is not affected by the app
  scale on the Settings page (only the Windows scale applies), so 150 x 46 looks like 150 x 46.
- While you change the name, text, shape, size or colours, the real button floating on screen changes
  too, before you save. Cancel puts it back. Nothing is written until you press Save.
- The width and height boxes update as you type.

## Not yet in this preview

- Editing on the screen itself (drag and resize handles, an edit mode) is not done.
- The preview does not show the dwell gauge or the hover colour.
- The preview background is the window background (no light/dark switch).

## Compatibility

- No change to the profile or settings formats. No new command line options.

## Verification

- .NET solution build: 0 warnings, 0 errors.
- .NET tests: 245 tests (Core 105, App 103, Infrastructure 37; one focus-dependent live test was skipped),
  no failures. The render smoke draws the preview at a 200% app scale and checks that it stays
  150 x 46 and follows a width change; other tests check the preview values (out-of-range sizes are
  clamped as when saving, a blank name draws the old name) and that closing the window takes the
  preview off the real button without writing settings.
- Live, on a copy of the real profiles with temporary registry keys and a disposable window, driven by
  UI Automation: setting the width to 300 in the properties window widened the real button window from
  241 to 481 physical pixels (the PC scales 160%), and Cancel returned it to 241. The real
  `profiles.json` and the copy were not changed.
