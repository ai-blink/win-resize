# WindowResizer v0.01.3

## 변경 사항

- Windows 세션별 named mutex를 추가해 앱의 중복 실행을 막았습니다.
- 이미 실행 중인 상태에서 다시 실행하면 메인 창을 열지 않고 안내 후 종료합니다.
- 정상 종료와 시작 중 예외 경로에서 mutex 핸들을 해제합니다.
- 창 제목, 트레이 표시, 실행 파일 메타데이터를 0.01.3으로 동기화했습니다.

## 검증

- 전체 단위 테스트: 35개 통과
- PyInstaller 단일 EXE 빌드 통과
- EXE 파일 버전 및 제품 버전: 0.01.3
- native mutex 획득, 중복 거부, 해제 후 재획득 확인

## 개인정보

프로필은 로컬 실행 파일 경로를 포함할 수 있습니다. 이 릴리즈에는 EXE 단일 파일만 포함되며, 로컬 프로필과 로그는 포함하지 않습니다.
