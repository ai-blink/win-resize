# WindowResizer v0.01.2

## 변경 사항

- 기본 창 크기를 현재 화면의 작업 영역 안에서 계산하도록 수정했습니다.
- 위치 프리셋이 선택한 대상 창이 있는 모니터의 작업 영역을 기준으로 계산됩니다.
- 혼합 DPI 모니터 환경에서 프로필 미리보기 위치를 Win32 물리 좌표와 Qt 좌표 사이에서 올바르게 변환합니다.
- 프로필 편집기의 창 설정 탭을 스크롤 가능한 컴팩트 레이아웃으로 정리해 버튼과 라벨이 잘리지 않도록 했습니다.
- 선택한 창에서 새 프로필을 만들 때 제목, 프로세스, 실행 파일 경로, 현재 좌표와 크기를 자동으로 채웁니다.
- 새 프로필 저장이 실패하면 편집기를 닫지 않고 입력 내용을 유지합니다.

- PyInstaller 단일 EXE 빌드 통과
- EXE 파일 버전 및 제품 버전: 0.01.2

## 개인정보

프로필은 로컬 실행 파일 경로를 포함할 수 있습니다. 이 릴리즈에는 EXE 단일 파일만 포함되며, 로컬 프로필과 로그는 포함하지 않습니다.
