# WindowResizer v0.02.0-preview.7

[English](v0.02.0-preview.7.md) | [한국어](v0.02.0-preview.7.ko.md) | [中文](v0.02.0-preview.7.zh-CN.md) | [日本語](v0.02.0-preview.7.ja.md)

リリース日: 2026-09-30

書き直した WPF（.NET 10）デスクトップアプリの 7 番目のプレビューです。`next/` 以下のソースから
ビルドし、配布される実行ファイルは引き続き PyQt5 アプリ v0.01.5 です。今回はオーバーレイボタンの
右クリックメニューを改善しました。

## 主な変更

- オーバーレイボタンの右クリックメニューが、そのボタンが何に対応しているかを示します。上から:
  プロファイル名（太字、クリック不可）、プロファイルが対象にするもの（実行ファイル名とフルパス、または
  ウィンドウタイトル・プロセス名のパターンと一致方式）、保存された位置とサイズ、「このプロファイルを
  編集...」、「このボタンを閉じる」。
- 「このプロファイルを編集...」は、メインウィンドウでどのプロファイルが選択されていても、そのプロファイルの
  編集ウィンドウを直接開きます。保存はプロファイル一覧で編集するときと同じ経路です。
- 「このボタンを閉じる」は従来どおりで、そのプロファイルのオーバーレイだけをオフにします。

## このプレビューにまだ無いもの

- ボタンのツールチップは変わっていません。
- Windows の 100/125/150/200% スケーリング確認は未検証のままです。
- インストーラーや更新の仕組み、v0.01.5 の実行ファイルの置き換え。

## 互換性

- プロファイルと設定の形式は変わりません。新しいコマンドラインオプションはありません。

## 検証

- .NET ソリューションのビルド: 警告 0 件、エラー 0 件。
- .NET テスト: 233 件、すべて成功（Core 99、App 97、Infrastructure 37）。新しいテストは、全ての一致方式の
  メニュー行、ID によるプロファイル編集（他のプロファイルは変わらず、未知の ID では何も開かない）、
  メニューを開いて 2 つの項目を押すレンダリングスモークを対象にします。
- 実行中のオーバーレイボタンへの実際のマウス右クリックは検証できませんでした。PC を使用中でカーソルが
  動き続け、ウィンドウメッセージで送ったクリックではメニューが開きませんでした。
