# WindowResizer v0.02.0-preview.4

[English](v0.02.0-preview.4.md) | [한국어](v0.02.0-preview.4.ko.md) | [中文](v0.02.0-preview.4.zh-CN.md) | [日本語](v0.02.0-preview.4.ja.md)

Release date: 2026-09-30

Fourth preview of the rewritten WPF (.NET 10) desktop app. Like the earlier previews
it is built from source under `next/` and is not a packaged release; the
distributed executable is still the PyQt5 app, v0.01.5.

## Highlights

- Settings page. Theme (light, dark, or follow the system), display size, language,
  run at Windows startup, and remembering the window size and position. Every change
  is saved and applied at once; nothing needs a restart.
- Theme. "Follow system" tracks the Windows app mode while the app is running.
  When Windows high contrast is on, its colors are always used, whatever is chosen.
- Display size, 75% to 125% in 5% steps (default 100%). Text, spacing and controls
  grow together, and the window grows with them. While you drag the slider only a
  preview sample changes; the size is applied when you let go, because applying it
  while dragging would move the slider away from your hand. Keys and clicks on the
  track apply at once. A reset button returns to 100%.
- Language, Korean or English, switched without reopening the window. It covers the
  screens, the menu, the tray menu and the shortcut lists.
- Run at Windows startup adds an entry for the current user (no administrator rights)
  that starts the app in the tray only, without opening the window (`--minimized`).
  The check box shows what Windows has registered, not a copy of its own.
- Remember window size and position. The main window reopens where it was; a place
  that is off every monitor (a monitor was removed, the resolution changed) is moved
  back onto the screen, and a window is never smaller than its minimum.
- First run imports the theme and display size from the v0.01.5 settings (on the test
  PC: follow system, 75%) and stores them separately under
  `HKCU\Software\WindowResizer\Next\Settings`; the v0.01.5 keys are never written.
  The v0.01.5 window size and position are not imported: they are Qt logical
  pixels and the old 920x640 window is smaller than this app's minimum. Its
  "high contrast" color scheme maps to follow system, which uses Windows high contrast.

## Not yet in this preview

- Log and about page, app icon and a packaged executable.
- The display size scaling smoke on Windows scale 100/125/150/200% (needs the Windows
  scaling changed by hand).
- Title bar, scroll bars and drop-down scroll bars stay light in dark mode.
- Custom color schemes (a JSON theme file in v0.01.5) are not supported.

## Compatibility

- `--settings-key <registry path>` points the settings at another key (and skips the
  import) and `--run-key <registry path>` points the startup entry at another Run key,
  for testing. `--minimized` starts in the tray only.

## Verification

- .NET solution build: 0 warnings, 0 errors.
- .NET tests: 201 tests, all passed (Core 89, App 75, Infrastructure 37): value rules,
  the one-time import (including a DWORD scale value as v0.01.5 writes it), window
  placement fitting, the drag rule, the startup entry, and a render smoke of the
  settings page at 125%.
- On the running app against a copy of the profiles and temporary registry keys, with
  real key presses and a real mouse drag: each theme card changed the colors at once and
  saved; follow system matched Windows; arrow keys changed the size (window grew 10%);
  dragging the slider changed nothing until the button was released, then applied and saved;
  reset returned to 100%; the language switch changed the sidebar text both ways;
  the startup check box wrote and removed a quoted command ending in `--minimized`;
  the window closed to the tray saved its place and reopened at the same position and size
  (within 3 px); turning memory off deleted the saved values; a saved place far off screen
  reopened fully on screen; `--minimized` kept the process running with no window.
  The real profile file, the real settings key and the real startup list were unchanged.
