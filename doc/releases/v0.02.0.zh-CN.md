# WindowResizer v0.02.0

[English](v0.02.0.md) | [한국어](v0.02.0.ko.md) | [中文](v0.02.0.zh-CN.md) | [日本語](v0.02.0.ja.md)

发布日期：2026-09-30

重写后的 WindowResizer 的首个正式版。分发的可执行文件由 PyQt5 应用（v0.01.5）改为本应用：基于 .NET 10 的 WPF，
以自带 .NET 运行时的单个自包含 `WindowResizer.exe`（约 72 MB）发布。

`WindowResizer.exe` 的 SHA-256：`9323D2A52C49C7A96FBD92E64FB6F57EEDDA001ED5E84A698DCC29843497F373`

## 主要变更

- 带侧边栏的五个页面：窗口与配置文件、悬浮按钮、快捷键、设置、日志与关于。
- 配置文件：保存窗口位置（Ctrl+S）、应用到所有匹配窗口、用某个窗口覆盖位置（可撤销），按可执行文件路径、进程名、标题
  （包含、完全一致、正则）或组合匹配。以相同格式读写现有 v0.01.5 的 `profiles.json`，应用不认识的键会保留。
- 位置锁定：被拖动或改变大小的配置文件窗口会回到应用时的位置（遵循配置文件的容差、移动时恢复、调整大小时恢复和最大尝试
  次数）。最大化和最小化的窗口不会被处理。无法移动的窗口（例如管理员权限窗口）在达到配置文件的最大尝试次数后放弃，并在状态栏提示。
- 鼠标限制：只在配置文件的窗口位于最前面时把鼠标限制在该窗口内；切换到其他窗口时解除，回来时再次限制。配置文件的退出键
  （默认 Escape）可解除，直到再次应用配置文件。
- 新窗口自动应用：应用启动后出现且匹配自动应用配置文件的窗口，会按该配置文件的 `apply_delay`、`max_retries` 和
  `retry_delay` 自动应用。多个配置文件匹配时只应用最具体的一个，启动时已经打开的窗口不受影响。状态栏显示“正在监视新窗口：N 个配置文件”。
- 悬浮按钮：每个按钮独立于配置文件，保存自己的名称以及要恢复的窗口位置和大小，按下后把刚才使用的窗口移到那里。属性窗口
  （常规、大小和位置、行为、外观）带实际大小预览；位置可从上一个窗口获取，也可像截图工具那样在屏幕上带轮廓地选择窗口。
  v0.01.5 中开启过悬浮按钮的配置文件会在首次启动时一次性复制为按钮。
- 每个配置文件的全局快捷键（多个组合和动作）、全部应用快捷键和置顶切换；被其他程序占用的组合会连同原因一起列出。
- 设置：浅色、深色或跟随系统主题（支持 Windows 高对比度），75% 到 250% 的应用缩放，韩语或英语界面，随 Windows 启动，
  记住窗口位置。
- 日志页面记录所有状态消息和未处理错误，可复制或导出。
- 单实例：同一 Windows 会话只运行一份（与 v0.01.5 使用同一个互斥体，两个应用不会同时运行）；第二次启动会把第一个窗口带到前面，而不是毫无反应。
- 关闭窗口后应用驻留在系统托盘；Ctrl+Q 或托盘菜单退出。

## 与 v0.01.5 相比的变化

- 切换到其他窗口后，鼠标不再被继续限制（v0.01.5 会一直保持到按下解除快捷键）。
- 配置文件的退出键现在有效（v0.01.5 只保存不使用）。
- 锁定恢复到窗口移动后的实际位置，而不是配置文件中的值，因此有最小尺寸的窗口不会永远与锁定对抗。
- 新窗口自动应用遵循各配置文件的延迟和重试设置（v0.01.5 使用固定值），也不需要单独的启动按钮：只要有一个启用了自动应用的配置文件就会运行。
- 悬浮按钮与配置文件分离，“全部关闭”改为“隐藏所有按钮”。

## 本版本尚未包含

- v0.01.5 的三秒配置文件预览轮廓。
- 应用界面的中文和日文（只有韩语和英语；文档有四种语言）。
- 安装程序和更新机制。
- 悬浮按钮在屏幕上的编辑模式（拖动和调整大小手柄），以及“用当前窗口的位置覆盖”的撤销。
- 配置文件编辑窗口仍显示“使用悬浮按钮”，它不再创建按钮。

## 兼容性

- 配置文件保持 v0.01.5 的格式。设置保存在 `HKCU\Software\WindowResizer\Next`；v0.01.5 的主题、应用缩放和悬浮设置只在首次启动时读取一次，不会写回。
- Windows 10 或 11，64 位。以管理员权限运行的窗口无法被普通权限的 WindowResizer 控制，需要时请以相同权限运行。
