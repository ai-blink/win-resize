# WindowResizer v0.02.0-preview.9

[English](v0.02.0-preview.9.md) | [한국어](v0.02.0-preview.9.ko.md) | [中文](v0.02.0-preview.9.zh-CN.md) | [日本語](v0.02.0-preview.9.ja.md)

发布日期：2026-09-30

重写的 WPF（.NET 10）桌面应用的第九个预览版，从 `next/` 下的源码构建；分发的可执行文件仍是
PyQt5 应用 v0.01.5。本预览为悬浮按钮属性窗口增加了实际大小预览。

## 主要变更

- 按钮属性窗口的外观页面以屏幕上的实际大小预览按钮。它与真实按钮使用同一段代码绘制，且不受设置页面中的
  应用缩放影响（只跟随 Windows 缩放），所以 150 x 46 看起来就是 150 x 46。
- 修改名称、文字、形状、大小或颜色时，屏幕上悬浮的真实按钮会在保存前同步变化。取消后恢复原样。按下保存
  之前不会写入任何内容。
- 宽度和高度输入框会随输入即时更新。

## 本预览尚未包含

- 直接在屏幕上编辑（拖动、调整大小手柄、编辑模式）尚未完成。
- 预览不显示停留进度条和鼠标悬停时的颜色。
- 预览背景就是窗口背景（没有明暗切换）。

## 兼容性

- 配置文件和设置格式没有变化。没有新的命令行选项。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：245 个（Core 105、App 103、Infrastructure 37；1 个依赖焦点的实机测试被跳过），无失败。
  渲染冒烟测试在 200% 应用缩放下绘制预览，确认其保持 150 x 46 并随宽度变化；其他测试检查预览值
  （超出范围的大小与保存时一样被修正，名称为空时显示原名称），以及关闭窗口时撤下真实按钮上的预览且
  不写入设置。
- 使用真实配置文件的副本、临时注册表键和一次性窗口，通过 UI Automation 验证：在属性窗口把宽度改为 300
  后，真实按钮窗口从 241 变宽到 481 物理像素（这台电脑缩放 160%），取消后回到 241。真实的
  `profiles.json` 和副本均未改变。
