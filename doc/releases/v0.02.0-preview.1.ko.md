# WindowResizer v0.02.0-preview.1

[English](v0.02.0-preview.1.md) | [한국어](v0.02.0-preview.1.ko.md) | [中文](v0.02.0-preview.1.zh-CN.md) | [日本語](v0.02.0-preview.1.ja.md)

릴리스 날짜: 2026-09-27

새로 작성한 WPF(.NET 10) 데스크톱 앱의 첫 미리보기입니다. `next/` 아래 소스에서
빌드하며 패키지로 배포하지 않습니다. 배포 실행 파일은 계속 PyQt5 앱 v0.01.5입니다.

## 주요 변경

- 왼쪽 사이드바가 있는 새 메인 창. 창 목록과 프로필이 나란히 있고, Ctrl+F 로
  검색하며, Enter 는 창 목록을 새로 연 뒤 선택한 프로필을 맞는 창 전부에 적용합니다.
- 창에서 프로필 만들기: "새 프로필로 저장"(Ctrl+S)은 선택한 창의 위치와 프로그램
  이름(겹치면 번호)으로 채운 편집 창을 엽니다. "위치 덮어쓰기"는 창의 위치로 프로필을
  갱신하고, 상태 줄에서 되돌릴 수 있습니다(Ctrl+Z).
- 사이드바 5페이지 편집 창: 일반, 대상 창, 위치와 크기, 실행 방법, 고급. 사본을
  고치고, 저장 전에 입력을 검사하며, 보이지 않는 항목도 지킵니다. "현재 창에서
  가져오기"는 맞는 창이 여러 개면 고르게 합니다.
- 최대화나 최소화된 창은 원래(일반) 위치로 가져옵니다. 최소화된 창의 -32000 좌표는
  저장하지 않습니다.
- 더 안전한 프로필 파일: 저장이 실패하면 변경을 되돌립니다. 읽지 못한 프로필은
  버리지 않고 파일에 남기며 목록에 흐리게 보입니다. 파일 전체를 읽지 못하면 읽기
  전용으로 엽니다.
- 창을 닫으면 트레이로 숨깁니다. 프로그램 종료(사이드바 맨 아래, Ctrl+Q, 트레이
  메뉴)는 실제로 끝냅니다. v0.01.5 에서는 메뉴 "종료"가 숨기기만 했습니다.
- 오버레이 설정 페이지, 오버레이 메뉴, 트레이 항목: 클릭/드웰, 드웰 시간, 감추기,
  감추기 스위치, 위치 잠금, 프로필별 버튼, 모두 닫기.
- 한국어와 영어 화면. 시스템의 밝은/어두운 테마를 따릅니다.

## 이 미리보기에 아직 없는 것

- 오버레이 버튼 창과 감추기 스위치(설정은 이미 저장됩니다).
- 단축키 페이지, 설정 페이지(테마, UI 크기, 언어), 로그와 정보 페이지.
- 앱 아이콘과 패키지 실행 파일.

## 호환성

- 프로필은 같은 `profiles.json` 형식이며, PyQt5 가 미리보기가 쓴 파일을 읽습니다.
  미리보기는 넘겨받은 폴더(`--profiles-dir`)에 쓰므로 프로필 폴더의 사본으로
  시험하세요.
- 오버레이 설정은 별도 레지스트리 키 `HKCU\Software\WindowResizer\Next\Overlay` 에
  물리 픽셀로 저장합니다. 첫 실행 때 v0.01.5 의 클릭/드웰, 드웰 시간, 감추기,
  스위치, 잠금 값을 가져옵니다. 예전 좌표는 단위가 달라 버튼 위치는 새로 시작합니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 102개 통과. 실제 Notepad 창(적용, 네 상태 캡처), 실제 키 입력, 커서
  제한, 전경 창 추적, 바인딩 오류 0건 화면 그리기 라이브 확인을 포함합니다.
- 실행 중인 앱에서: 창을 닫으면 프로세스가 트레이에 남고, 사이드바의 프로그램 종료
  버튼으로 끝납니다.
