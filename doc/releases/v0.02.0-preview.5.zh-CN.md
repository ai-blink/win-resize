# WindowResizer v0.02.0-preview.5

[English](v0.02.0-preview.5.md) | [한국어](v0.02.0-preview.5.ko.md) | [中文](v0.02.0-preview.5.zh-CN.md) | [日本語](v0.02.0-preview.5.ja.md)

发布日期：2026-09-30

重写的 WPF（.NET 10）桌面应用的第五个预览版。与之前的预览版一样，它从 `next/` 下的源码构建，
不是打包发布版；对外分发的可执行文件仍是 PyQt5 应用 v0.01.5。

## 主要变化

- 日志与关于页面。上半部分显示应用当前使用的内容：版本、.NET 运行时、是否以管理员身份运行（否则无法移动
  以管理员身份运行的程序的窗口）、可执行文件、配置文件夹，以及设置、悬浮按钮和快捷键的注册表键。针对副本
  测试时，可以在这里直观确认没有触碰真实的配置文件夹和真实的键。按钮可在资源管理器中打开配置文件夹、
  复制全部内容（用于报告问题）或复制设置键路径。
- 下半部分的日志取代 PyQt5 的调试窗口。新应用没有日志框架，因此记录你本来就能看到的内容：状态栏中出现的
  每条消息（带时间），以及带完整详情的未处理错误。每行分为信息、警告或错误（保存或应用失败、没有匹配的窗口、
  设置键无法写入属于警告）。可以显示全部、警告及以上或仅错误；保留 100 到 10000 行（先丢弃最旧的）；开关
  自动滚动；清除日志；把当前显示的内容复制到剪贴板；或导出为带标题的 UTF-8 文本文件。警告行加粗并带颜色，
  文字中也写有 WARNING 或 ERROR，不只依赖颜色。
- 菜单栏：工具 > 日志（Ctrl+D）和帮助 > 关于会打开此页面，兑现了菜单图的约定。v0.01.5 中版本号写死的
  英文关于对话框已移除。
- 界面异常不再结束应用。它会作为错误记录在日志中并显示在状态栏，应用继续在托盘中运行。其他线程上的错误会在
  运行时结束进程之前写入日志。
- 切换语言时，级别名称和行数文字也会重建；已记录的行保持写入时的语言。

## 本预览版尚未包含

- 日志仅在本次运行期间保存在内存中，导出之前不会写入文件。
- 应用图标、打包的可执行文件，以及 Windows 缩放 100/125/150/200% 检查。
- 深色模式下标题栏、滚动条和下拉列表滚动条仍是浅色。
- 侧边栏会截短英文“Windows and profiles”标签。

## 兼容性

- 配置文件和设置的格式没有变化。没有新的命令行选项。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：227 个，全部通过（Core 99、App 91、Infrastructure 37）：日志（添加、最大行数、丢弃、筛选、
  导出文本）、页面视图模型（实时行、筛选、清除、仅复制可见行、带 BOM 的导出、剪贴板被占用、无法写入的路径）、
  状态栏到日志级别的对应、未处理错误条目、关于页面，以及无绑定错误地绘制所有页面的冒烟测试。
- 在仅含一个无匹配窗口的配置文件副本上运行的应用中，使用真实按键和真实的保存对话框：Ctrl+D 打开页面且有
  启动行；信息中显示本次构建的版本以及副本文件夹和临时注册表键（不是真实的）；更改主题以信息行出现；应用
  没有匹配窗口的配置文件以警告行出现；筛选把列表缩减为一条警告，再到空列表和提示文字，然后恢复全部；
  “全部复制”把五行都放进剪贴板（剪贴板文本已保存并恢复）；导出通过真实的保存对话框写出带 BOM 的 UTF-8 文件，
  含标题和各行；“打开配置文件夹”在资源管理器中打开副本文件夹；清除使列表为空；帮助 > 关于打开该页面。
  真实的配置文件、真实的设置键和真实的启动列表均未改变。未处理异常的处理由单元测试覆盖，没有故意让运行中的
  应用崩溃。
