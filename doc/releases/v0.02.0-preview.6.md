# WindowResizer v0.02.0-preview.6

[English](v0.02.0-preview.6.md) | [한국어](v0.02.0-preview.6.ko.md) | [中文](v0.02.0-preview.6.zh-CN.md) | [日本語](v0.02.0-preview.6.ja.md)

Release date: 2026-09-30

Sixth preview of the rewritten WPF (.NET 10) desktop app. Like the earlier previews
it is built from source under `next/`; the distributed executable is still the
PyQt5 app, v0.01.5. This preview adds an app icon and a way to build a single-file exe.

## Highlights

- App icon. The 3D window icon that already existed in the repository (a gray window with
  three coloured dots and a resize arrow) is now used everywhere: the exe in Explorer, the
  window title bars (main, profile editor, window picker), the taskbar and the tray. The old
  source was one 256 px picture, which turns into a grey blob when Windows shrinks it, so the
  icon file now holds nine sizes (16, 20, 24, 32, 40, 48, 64, 128, 256 px) and Windows picks the
  one that fits. `next/tools/make_app_icon.py` rebuilds the file from the source PNG.
- Single-file build. `next/tools/publish.ps1` publishes a self-contained single-file exe
  (`next/publish/win-x64/WindowResizer.App.exe`, 72.3 MB compressed) that carries its own
  .NET runtime, so it starts on a PC without .NET installed. On the test PC the first start
  took 3.4 s (it unpacks its native libraries into `%TEMP%\.net`) and later starts 1.6 s. The
  file is not distributed and does not replace the v0.01.5 executable.
- The file version now follows the preview number again (`0.2.0.6`; it was left at `.3`).

## Not yet in this preview

- The Windows 100/125/150/200% scaling smoke was skipped on request and is not verified.
- An installer or an update mechanism, and replacing the v0.01.5 executable.
- Title bar, scroll bars and drop-down scroll bars stay light in dark mode.
- The icon is the existing artwork resized; at 16 px it is a small grey window with coloured dots.

## Compatibility

- No change to the profile or settings formats. No new command line options.

## Verification

- .NET solution build: 0 warnings, 0 errors.
- .NET tests: 227 tests, all passed (Core 99, App 91, Infrastructure 37). The render smoke also
  checks that the icon file holds all nine sizes, that the tray picks the frame that fits
  (16 and 32 px), and that the main, editor and picker windows carry the icon.
- The published exe, run against a copy of the profiles and temporary registry keys: the publish
  folder holds only that one file; its version resource reads `0.02.0-preview.6`; the exe shows the
  app icon in Explorer; the window opens; no module is loaded from the installed .NET, only the
  native libraries it unpacked itself; screenshots show the icon in the window title bar and on
  the taskbar button, and Windows kept a snapshot of the tray icon that is the same picture.
  The real profile file, settings key and the v0.01.5 executable were untouched.
