# WindowResizer v0.02.0-preview.2

[English](v0.02.0-preview.2.md) | [한국어](v0.02.0-preview.2.ko.md) | [中文](v0.02.0-preview.2.zh-CN.md) | [日本語](v0.02.0-preview.2.ja.md)

릴리스 날짜: 2026-09-29

새로 작성한 WPF(.NET 10) 데스크톱 앱의 두 번째 미리보기입니다. preview.1 과 같이
`next/` 아래 소스에서 빌드하며 패키지로 배포하지 않습니다. 배포 실행 파일은 계속
PyQt5 앱 v0.01.5 입니다.

## 주요 변경

- 오버레이 버튼이 화면에 뜹니다. 오버레이 버튼을 켠 프로필마다 떠 있는 버튼이 하나
  생기고, 직전에 쓰던 창에 그 프로필을 적용합니다. 클릭하거나, 마우스를 드웰 시간
  (0.2~5.0초) 동안 올려 두고 게이지가 차는 것을 보면 됩니다. 끌어서 옮기고, 위치를
  잠그고, 우클릭으로 닫으며, 결과는 초록/빨강 깜빡임으로 보입니다. 저장된 위치는 연결된
  모니터 안에 있을 때만 씁니다. v0.01.5 와 같이 버튼은 프로필의 매칭 조건이 고르지
  않을 창이어도 직전 창에 적용합니다.
- 버튼은 포커스를 가져가지 않습니다. 이번 미리보기에서 고쳤습니다: 버튼을 누르면
  WindowResizer 자기 창이 올라와 "직전 창"이 WindowResizer 자신이 될 수 있었습니다.
  창 스타일과 클릭 활성화 차단을 함께 걸어 포커스가 쓰던 창에 남습니다.
- 감추기 스위치: 작은 눈 모양 버튼으로 오버레이 버튼을 한꺼번에 감추고 다시 보입니다.
  둔 자리를 기억하고, 자기 자신은 숨지 않으며, 스위치를 치우면 감춘 버튼이 다시
  보입니다. 몇 픽셀 끌다 만 것은 클릭으로 세지 않습니다.
- v0.01.5 의 오버레이 설정은 처음 한 번 가져옵니다(발동 방식, 드웰 시간, 감추기,
  스위치, 잠금). 거기서 버튼을 감춰 뒀다면 여기서도 감춘 채 시작하고, 되돌리는 길이
  스위치입니다. 버튼 위치는 새로 시작합니다.

## 이 미리보기에 아직 없는 것

- 단축키 페이지, 설정 페이지(테마, UI 크기, 언어), 로그와 정보 페이지.
- 앱 아이콘과 패키지 실행 파일.

## 호환성

- 프로필은 같은 `profiles.json` 형식입니다. 오버레이 설정은
  `HKCU\Software\WindowResizer\Next\Overlay` 에 물리 픽셀로 저장합니다. 미리보기는
  넘겨받은 프로필 폴더(`--profiles-dir`)에 쓰므로 사본으로 시험하세요.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 112개, 연속 세 번 재실행에서 모두 통과했습니다. 전체 실행 한 번에서는
  창을 전경으로 올려야 하는 실제 창 테스트가 Windows 가 포커스 이동을 막아 판정 불가로
  건너뛰었습니다.
- 실행 중인 앱에서 실제 마우스 클릭으로: 오버레이 버튼을 누르면 대상 창이 앞에 남고,
  프로필 위치로 정확히 옮겨지며 적용 횟수가 저장됩니다. 감추기 스위치는 포커스를
  가져가지 않고 버튼을 감췄다 다시 보였으며, 끌면 끈 거리만큼 정확히 옮겨지고 새 위치가
  저장되며 감춤은 바뀌지 않았습니다.
