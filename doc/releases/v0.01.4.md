# WindowResizer v0.01.4

## 변경 사항

- `전체 적용`이 비동기 창 목록 새로고침 완료 후 최신 창 목록에 프로필을 적용합니다.
- WindowResizer 실행 뒤 새로 열린 대상 창도 한 번의 클릭으로 매칭하고 적용합니다.
- 창 제목, 정보 대화상자, 시스템 트레이, 실행 파일 메타데이터의 버전을 0.01.4로 동기화했습니다.

- PyInstaller 단일 EXE 빌드 통과
- EXE 파일 버전 및 제품 버전: 0.01.4
