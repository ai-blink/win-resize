[English](v0.01.4.md) | [한국어](v0.01.4.ko.md) | [中文](v0.01.4.zh-CN.md) | [日本語](v0.01.4.ja.md)

Release date: 2026-08-10

## Highlights

- Apply All waits for asynchronous window-list refresh before matching and
  applying profiles to the latest list.
- A target window opened after WindowResizer starts can be matched and updated
  with one Apply All action.
- Synchronized the version to 0.01.4 in the window title, information dialogs,
  system tray, and executable metadata.
