# WindowResizer v0.02.0-preview.4

[English](v0.02.0-preview.4.md) | [한국어](v0.02.0-preview.4.ko.md) | [中文](v0.02.0-preview.4.zh-CN.md) | [日本語](v0.02.0-preview.4.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WPF(.NET 10) 데스크톱 앱의 네 번째 미리보기입니다. 앞선 미리보기와 같이
`next/` 아래 소스에서 빌드하며 패키지로 배포하지 않습니다. 배포 실행 파일은 계속
PyQt5 앱 v0.01.5 입니다.

## 주요 변경

- 설정 페이지. 테마(밝게, 어둡게, 시스템 따르기), 화면 크기, 언어, Windows 시작 때 자동
  실행, 창 크기와 위치 기억. 바꾸는 즉시 저장하고 적용하며 다시 시작할 필요가 없습니다.
- 테마. "시스템 따르기"는 앱이 떠 있는 동안 Windows 앱 모드를 따라갑니다. Windows 고대비가
  켜져 있으면 무엇을 골랐든 항상 그 색을 씁니다.
- 화면 크기는 75%에서 125%까지 5% 단위입니다(기본 100%). 글자, 여백, 컨트롤이 함께 커지고
  창도 같이 커집니다. 슬라이더를 끄는 동안에는 미리보기 견본만 바뀌고, 놓을 때 적용합니다 -
  끄는 도중에 적용하면 슬라이더가 손 밑에서 움직이기 때문입니다. 키와 트랙 클릭은 바로
  적용합니다. 초기화 버튼은 100%로 되돌립니다.
- 언어는 한국어와 영어이며 창을 다시 열지 않고 바뀝니다. 화면, 메뉴, 트레이 메뉴, 단축키
  목록까지 바뀝니다.
- Windows 시작 때 자동 실행은 현재 사용자의 시작 항목을 추가하며(관리자 권한 불필요) 창을
  열지 않고 트레이로만 뜹니다(`--minimized`). 체크 상자는 자기 사본이 아니라 Windows 에
  등록된 상태를 보여 줍니다.
- 창 크기와 위치 기억. 메인 창이 있던 자리에서 다시 열립니다. 모든 모니터 밖의 자리(모니터를
  뺐거나 해상도가 바뀐 경우)는 화면 안으로 옮기고, 최소 크기보다 작게는 열지 않습니다.
- 처음 실행하면 v0.01.5 설정에서 테마와 화면 크기를 가져오고(시험 PC 에서는 시스템 따르기,
  75%) `HKCU\Software\WindowResizer\Next\Settings` 에 따로 저장합니다. v0.01.5 키에는 쓰지
  않습니다. v0.01.5 의 창 크기와 위치는 Qt 논리 픽셀이고 옛 창(920x640)이 이 앱의 최소
  크기보다 작아 가져오지 않습니다. "고대비" 색 구성표는 시스템 따르기로 옮깁니다
  (Windows 고대비를 켜면 그 색이 나옵니다).

## 이 미리보기에 아직 없는 것

- 로그와 정보 페이지, 앱 아이콘, 패키지 실행 파일.
- Windows 배율 100/125/150/200%에서의 화면 크기 확인(Windows 배율을 손으로 바꿔야 합니다).
- 다크 모드에서 제목 줄, 스크롤바, 드롭다운 스크롤바가 아직 밝습니다.
- 사용자 정의 색 구성표(v0.01.5 의 JSON 테마 파일)는 지원하지 않습니다.

## 호환성

- `--settings-key <레지스트리 경로>` 는 설정을 다른 키에 두고(가져오기도 건너뜁니다),
  `--run-key <레지스트리 경로>` 는 시작 항목을 다른 Run 키에 둡니다(시험용). `--minimized`
  는 트레이로만 뜹니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 201개, 모두 통과했습니다(Core 89, App 75, Infrastructure 37): 값 규칙, 처음
  한 번 가져오기(v0.01.5 가 쓰는 DWORD 배율 값 포함), 창 자리 보정, 끄는 동안의 규칙, 시작
  항목, 125% 에서 설정 페이지를 그려 보는 스모크.
- 프로필 사본과 임시 레지스트리 키로 실행 중인 앱에서 실제 키 입력과 실제 마우스 끌기로:
  테마 카드마다 색이 바로 바뀌고 저장됐고, 시스템 따르기는 Windows 와 같았고, 방향키로 크기가
  바뀌었고(창이 10% 커짐), 슬라이더를 끄는 동안에는 아무것도 바뀌지 않다가 놓자 적용되고
  저장됐고, 초기화는 100%로 돌아갔고, 언어 전환은 사이드바 글자를 양쪽으로 바꿨고, 시작
  체크 상자는 `--minimized` 로 끝나는 따옴표 명령을 썼다가 지웠고, 트레이로 닫은 창은 자리를
  저장해 같은 위치와 크기(3 px 이내)로 다시 열렸고, 기억을 끄면 저장값이 지워졌고, 화면 훨씬
  밖으로 저장된 자리는 화면 안에서 열렸고, `--minimized` 는 창 없이 프로세스만 유지했습니다.
  실제 프로필 파일, 실제 설정 키, 실제 시작 목록은 바뀌지 않았습니다.
