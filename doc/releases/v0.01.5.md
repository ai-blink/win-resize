# WindowResizer v0.01.5

[English](v0.01.5.md) | [한국어](v0.01.5.ko.md) | [中文](v0.01.5.zh-CN.md) | [日本語](v0.01.5.ja.md)

Release date: 2026-09-25

## Highlights

- Added per-profile overlay buttons that apply a profile by click or dwell
  without taking foreground focus, plus a global overlay hide switch.
- Profile shortcut sets now persist across restarts. A Settings menu command
  configures a separate global shortcut for applying all matching profiles.
- Apply All now checks every matching window. Failed native window operations
  remain failures instead of being reported as successful applications.
- Added the initial .NET 10 WPF solution scaffold and layer-boundary tests for
  the migration. This release still distributes the PyQt5 desktop application.
