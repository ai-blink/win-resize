# WindowResizer v0.02.0-preview.9

[English](v0.02.0-preview.9.md) | [한국어](v0.02.0-preview.9.ko.md) | [中文](v0.02.0-preview.9.zh-CN.md) | [日本語](v0.02.0-preview.9.ja.md)

릴리스 날짜: 2026-09-30

새로 작성한 WPF(.NET 10) 데스크톱 앱의 아홉 번째 미리보기입니다. `next/` 아래 소스에서 빌드하며,
배포 실행 파일은 계속 PyQt5 앱 v0.01.5 입니다. 이번에는 오버레이 버튼 속성 창에 실제 크기 미리보기를
넣었습니다.

## 주요 변경

- 버튼 속성 창의 외형 페이지가 버튼을 화면에 뜨는 실제 크기로 미리 보여 줍니다. 실제 버튼과 같은 코드로
  그리고, 설정 페이지의 앱 배율에 영향을 받지 않아서(Windows 배율만 따름) 150 x 46 이 150 x 46 으로
  보입니다.
- 이름, 글자, 모양, 크기, 색을 바꾸는 동안 화면에 떠 있는 실제 버튼도 저장 전에 같이 바뀝니다. 취소하면
  원래대로 돌아갑니다. 저장을 누르기 전에는 아무것도 쓰지 않습니다.
- 폭과 높이 칸은 입력하는 대로 바로 반영됩니다.

## 이 미리보기에 아직 없는 것

- 화면에서 바로 하는 편집(끌어서 옮기기, 크기 손잡이, 편집 모드)은 아직 없습니다.
- 미리보기는 머무르기 게이지와 마우스를 올렸을 때의 색을 보이지 않습니다.
- 미리보기 배경은 창 배경 그대로입니다(밝게/어둡게 전환 없음).

## 호환성

- 프로필과 설정 형식은 바뀌지 않습니다. 새 명령줄 옵션은 없습니다.

## 검증

- .NET 솔루션 빌드: 경고 0개, 오류 0개.
- .NET 테스트: 245개(Core 105, App 103, Infrastructure 37, 포커스에 의존하는 라이브 테스트 1개는
  건너뜀), 실패 없음. 렌더 스모크가 앱 배율 200%에서 미리보기를 그려 150 x 46 을 유지하고 폭 변경을
  따라가는지 확인하고, 다른 테스트가 미리보기 값(범위 밖 크기는 저장 때처럼 보정, 이름을 비우면 원래
  이름)과 창을 닫을 때 설정을 쓰지 않고 실제 버튼의 미리보기를 걷는지를 확인합니다.
- 실제 프로필 사본과 임시 레지스트리 키, 일회용 창으로 UI Automation 을 써서 확인했습니다: 속성 창에서
  폭을 300 으로 바꾸자 실제 버튼 창이 241 에서 481 물리 픽셀로 넓어졌고(이 PC 는 160% 배율), 취소하자
  241 로 돌아왔습니다. 실제 `profiles.json` 과 사본은 바뀌지 않았습니다.
