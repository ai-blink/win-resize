# WindowResizer v0.02.0-preview.2

[English](v0.02.0-preview.2.md) | [한국어](v0.02.0-preview.2.ko.md) | [中文](v0.02.0-preview.2.zh-CN.md) | [日本語](v0.02.0-preview.2.ja.md)

发布日期：2026-09-29

重写后的 WPF（.NET 10）桌面应用的第二个预览版。与 preview.1 一样，它从 `next/` 下的源码
构建，不是打包发布版；分发的可执行文件仍是 PyQt5 应用 v0.01.5。

## 主要变更

- 悬浮按钮现已显示在屏幕上。每个开启了悬浮按钮的配置文件都会有一个浮动按钮，把该配置文件
  应用到你刚才使用的窗口：点击它，或把鼠标停留在上面直到停留时间（0.2-5.0 秒）并看着进度
  条填满。可拖动移动、锁定位置、右键关闭，结果以绿色或红色闪烁显示。保存的位置只在仍位于
  已连接的显示器内时才会使用。与 v0.01.5 一样，即使配置文件的匹配条件不会选中该窗口，按钮
  也会把配置文件应用到最近位于前台的窗口。
- 按钮不会夺取焦点。此预览版已修复：以前点击按钮会把 WindowResizer 自己的窗口提到前面，
  于是“上一个窗口”就成了 WindowResizer 本身。现在窗口样式加上点击激活拦截，使焦点留在你的
  窗口上。
- 隐藏开关：一个小小的眼睛按钮，可一次隐藏和显示所有悬浮按钮。它会记住你放置的位置，自己
  不会隐藏，移除它会让已隐藏的按钮重新显示。拖动几个像素不算点击。
- 首次运行时会导入 v0.01.5 的悬浮按钮设置（触发方式、停留时间、隐藏、开关、锁定）。如果在
  那里按钮被隐藏，这里也会以隐藏状态启动，开关就是恢复的途径。按钮位置重新开始。

## 此预览版尚未包含

- 快捷键页、设置页（主题、界面缩放、语言）、日志与关于页。
- 应用图标和打包的可执行文件。

## 兼容性

- 配置文件使用相同的 `profiles.json` 格式。悬浮按钮设置以物理像素保存在
  `HKCU\Software\WindowResizer\Next\Overlay`。预览版会写入给定的配置文件夹
  （`--profiles-dir`），请使用副本测试。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：112 个，连续三次重新运行全部通过。在一次完整运行中，一个需要窗口位于前台的
  实时测试因 Windows 阻止焦点切换而以“无法判定”跳过。
- 在运行中的应用上使用真实鼠标点击：点击悬浮按钮后目标窗口保持在前台，被准确移动到配置
  文件的位置，并保存了应用次数。隐藏开关在不夺取焦点的情况下隐藏并重新显示了按钮；拖动它
  时移动的距离与拖动距离完全一致，保存了新位置，且没有触发切换。
