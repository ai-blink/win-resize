# WindowResizer v0.02.0-preview.1

[English](v0.02.0-preview.1.md) | [한국어](v0.02.0-preview.1.ko.md) | [中文](v0.02.0-preview.1.zh-CN.md) | [日本語](v0.02.0-preview.1.ja.md)

Release date: 2026-09-27

This is the first preview of the rewritten WPF (.NET 10) desktop app. It is built
from source under `next/` and is not a packaged release. The distributed
executable is still the PyQt5 app, v0.01.5.

## Highlights

- New main window with a left sidebar. Windows and profiles sit side by side;
  search with Ctrl+F; Enter applies the selected profile to every matching
  window after a fresh window scan.
- Profiles from windows: "Save as new profile" (Ctrl+S) opens the editor
  prefilled with the selected window's position and the program name (numbered
  if taken). "Overwrite position" updates a profile from a window, and the status
  line offers Undo (Ctrl+Z).
- Profile editor with five sidebar pages: General, Target window, Position and
  size, How to run, Advanced. It edits a copy, checks input before saving, keeps
  fields it does not show, and "Take from current window" asks when several
  windows match.
- Maximized and minimized windows are captured at their normal position; the
  -32000 coordinates of a minimized window are never saved.
- Safer profile file: a failed save rolls the change back; profiles that cannot
  be read are kept in the file and shown dimmed instead of being dropped; a file
  that cannot be read at all is opened read-only.
- Closing the window hides it to the tray. Exit program (bottom of the sidebar,
  Ctrl+Q, or the tray menu) quits for real. In v0.01.5 the menu Exit only hid
  the window.
- Overlay settings page, Overlay menu and tray items: click or dwell, dwell time,
  hide, hide switch, lock, per-profile buttons, close all.
- Korean and English interface; follows the system light or dark theme.

## Not yet in this preview

- The overlay button windows and the hide switch (settings are saved already).
- Hotkeys page, settings page (theme, UI scale, language), log and about page.
- App icon and a packaged executable.

## Compatibility

- Profiles use the same `profiles.json` format, and PyQt5 reads files written by
  the preview. Test against a copy of your profiles folder: the preview writes to
  the folder it is given (`--profiles-dir`).
- Overlay settings are stored in a separate registry key,
  `HKCU\Software\WindowResizer\Next\Overlay`, in physical pixels. On first run the
  preview imports the click/dwell, dwell time, hide, switch and lock values from
  v0.01.5; button positions start fresh because the old coordinates use a
  different unit.

## Verification

- .NET solution build: 0 warnings, 0 errors.
- .NET tests: 102 passed, including live checks on a real Notepad window
  (apply, capture in four states), real key input, cursor clip, foreground
  tracking, and window rendering with zero binding errors.
- On the running app: closing the window leaves the process in the tray, and the
  sidebar Exit program button ends it.
