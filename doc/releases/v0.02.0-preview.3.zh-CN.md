# WindowResizer v0.02.0-preview.3

[English](v0.02.0-preview.3.md) | [한국어](v0.02.0-preview.3.ko.md) | [中文](v0.02.0-preview.3.zh-CN.md) | [日本語](v0.02.0-preview.3.ja.md)

发布日期：2026-09-29

重写的 WPF（.NET 10）桌面应用的第三个预览版。与之前的预览版一样，它从 `next/` 下的源码
构建，不是打包发布版；分发的可执行文件仍是 PyQt5 应用 v0.01.5。

## 主要变更

- 快捷键页面。一个全局“全部应用”快捷键会把每个配置文件应用到其匹配的所有窗口（与新增的
  “配置文件 > 应用全部配置文件”菜单走同一路径）。每个配置文件最多可有三个快捷键，各自选择
  动作：应用配置文件、释放锁定、切换置顶、切换自动应用。每个配置文件有一个开关，可一次性
  开启或关闭它的全部快捷键。
- 页面列出每个快捷键及其注册结果。被其他程序占用的组合、格式错误的组合、未知动作和重复项
  会显示原因而不是悄悄失败，其余的仍会注册。每次保存或删除配置文件都会重新注册；不涉及快捷键
  的保存（例如应用次数）不会动注册。
- “全部应用”快捷键保存在 `HKCU\Software\WindowResizer\Next\Hotkeys`。首次运行时导入
  v0.01.5 文件 `application_hotkeys.json` 中的值（测试电脑上是 Ctrl+Alt+E），并且从不写入
  该文件。与 v0.01.5 一样，即使 Windows 拒绝注册，快捷键也会保存，页面会说明。
- 配置文件有快捷键组时，配置文件编辑窗口会关闭单个快捷键输入框并指向快捷键页面，因此在那里
  修改不会再毫无效果。配置文件列表的“快捷键”列显示已注册的第一个快捷键。

## 此预览版尚未包含

- “释放锁定”无可释放之物：此预览版尚不锁定窗口或限制鼠标，因此快捷键只在状态栏说明这一点。
- “切换自动应用”会翻转并保存配置文件的设置；检测新窗口并自动应用不在此预览版中。
- “切换置顶”与 v0.01.5 一样作用于最前面的窗口，而不是某个配置文件。
- 设置页面（主题、界面缩放、语言）、日志与关于页面、应用图标和打包的可执行文件。

## 兼容性

- 配置文件使用相同的 `profiles.json` 格式，包括 `hotkey_sets`；保存时与 PyQt5 编辑窗口一样，
  也会把第一组写入 `hotkey_combination` 和 `hotkey_action`。预览版会写入所指定的配置文件夹
  （`--profiles-dir`）：请用副本测试。`--hotkey-key` 用于测试时把“全部应用”快捷键指向另一个
  注册表项。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：144 个测试，全部通过（Core 66、App 49、Infrastructure 29），包括向注册层发送
  真实按键的测试。
- 在使用配置文件副本运行的应用上，用真实按键：“全部应用”快捷键 Ctrl+Alt+E 把一次性窗口移到
  配置文件的位置；配置文件快捷键应用了该配置文件；切换置顶把最前面的窗口开启再关闭；切换自动
  应用把设置双向翻转并保存。被其他程序占用的组合连同冲突原因显示在列表中，其余的仍保持已注册。
  真实的配置文件没有变化。
