# WindowResizer v0.02.0-preview.6

[English](v0.02.0-preview.6.md) | [한국어](v0.02.0-preview.6.ko.md) | [中文](v0.02.0-preview.6.zh-CN.md) | [日本語](v0.02.0-preview.6.ja.md)

发布日期：2026-09-30

重写的 WPF（.NET 10）桌面应用的第六个预览版。与之前的预览版一样，它从 `next/` 下的源码构建；对外分发的
可执行文件仍是 PyQt5 应用 v0.01.5。本预览版增加了应用图标和构建单文件 exe 的方法。

## 主要变化

- 应用图标。仓库中原有的 3D 窗口图标（灰色窗口、三个彩色圆点和一个调整大小的箭头）现在用于所有位置：
  资源管理器中的 exe、窗口标题栏（主窗口、配置文件编辑窗口、窗口选择窗口）、任务栏和托盘。旧的原图只有
  一张 256 px 图片，被 Windows 缩小后会变成一团灰色，所以图标文件现在包含九种尺寸（16、20、24、32、40、
  48、64、128、256 px），由 Windows 选用合适的一个。`next/tools/make_app_icon.py` 可从原始 PNG 重新生成
  该文件。
- 单文件构建。`next/tools/publish.ps1` 会发布一个自带 .NET 运行时的 self-contained 单文件 exe
  （`next/publish/win-x64/WindowResizer.App.exe`，压缩后 72.3 MB），在未安装 .NET 的电脑上也能启动。
  在测试电脑上首次启动 3.4 秒（需要把原生库解压到 `%TEMP%\.net`），之后每次 1.6 秒。该文件不对外分发，
  也不会替换 v0.01.5 的可执行文件。
- 文件版本重新跟随预览版号（`0.2.0.6`，此前停留在 `.3`）。

## 本预览版尚未包含

- 应要求跳过了 Windows 缩放 100/125/150/200% 的检查，未做验证。
- 安装程序或更新机制，以及替换 v0.01.5 的可执行文件。
- 深色模式下标题栏、滚动条和下拉列表滚动条仍是浅色。
- 图标是缩小的现有图案，在 16 px 时呈现为带彩色圆点的小灰色窗口。

## 兼容性

- 配置文件和设置的格式没有变化。没有新的命令行选项。

## 验证

- .NET 解决方案构建：0 个警告，0 个错误。
- .NET 测试：227 个，全部通过（Core 99、App 91、Infrastructure 37）。渲染冒烟测试还会检查图标文件是否
  包含全部九种尺寸、托盘是否选用合适的帧（16 和 32 px），以及主窗口、编辑窗口和选择窗口是否带有图标。
- 使用配置文件副本和临时注册表键运行发布的 exe：发布文件夹中只有这一个文件；版本资源为
  `0.02.0-preview.6`；资源管理器中 exe 显示应用图标；窗口可以打开；没有从已安装的 .NET 加载任何模块，
  只使用自己解压出的原生库；截图显示窗口标题栏和任务栏按钮上有该图标，Windows 保存的托盘图标快照是同一幅
  图案。真实的配置文件、真实的设置键和 v0.01.5 的可执行文件均未改变。
