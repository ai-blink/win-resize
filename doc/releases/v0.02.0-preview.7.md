# WindowResizer v0.02.0-preview.7

[English](v0.02.0-preview.7.md) | [한국어](v0.02.0-preview.7.ko.md) | [中文](v0.02.0-preview.7.zh-CN.md) | [日本語](v0.02.0-preview.7.ja.md)

Release date: 2026-09-30

Seventh preview of the rewritten WPF (.NET 10) desktop app, built from source under `next/`;
the distributed executable is still the PyQt5 app, v0.01.5. This preview improves the right-click
menu of the overlay buttons.

## Highlights

- The overlay button right-click menu now says what the button is for. From the top: the profile
  name (bold, not clickable); what the profile matches (the executable file name and the full path,
  or the window title or process name pattern, with the matching method); the saved position and
  size; "Edit this profile..."; and "Close this button".
- "Edit this profile..." opens that profile's editor directly, whichever profile is selected in the
  main window, and saving goes through the same path as editing from the profile list.
- "Close this button" is unchanged: it only turns off the overlay for that profile.

## Not yet in this preview

- The tooltip of the button is unchanged.
- The Windows 100/125/150/200% scaling smoke is still not verified.
- An installer or an update mechanism, and replacing the v0.01.5 executable.

## Compatibility

- No change to the profile or settings formats. No new command line options.

## Verification

- .NET solution build: 0 warnings, 0 errors.
- .NET tests: 233 tests, all passed (Core 99, App 97, Infrastructure 37). New tests cover the menu
  lines for every matching method, editing a profile by id (a different profile stays untouched, an
  unknown id opens nothing), and a render smoke that opens the menu and clicks its two items.
- A real mouse right-click on a running overlay button was not verified: the PC was in use and the
  cursor kept moving, so a click through window messages did not open the menu either.
