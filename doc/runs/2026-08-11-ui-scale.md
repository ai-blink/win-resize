# UI Scale Run Report

## Finish Line

Provide a live application-wide UI scale slider that persists its selected
value and makes the initial UI smaller by default without changing saved
profile geometry or native window operations.

## Delivered

- Added `UiScaleManager` with a persisted 90% default, 75% to 125% range, and
  5% increments.
- Added `보기 > UI 크기...` with a live slider and a 90% reset button.
- Persisted the last visible main-window size and position separately, then
  restore the window inside its saved screen or the current primary screen.
- Applied the selected scale to application fonts, explicit widget constraints,
  layouts, table columns, theme CSS, message boxes, profile dialogs, and tray
  dialogs.
- Kept profile coordinates, target window dimensions, and preview-overlay
  geometry independent from UI scale.
