## 0.01.3 - 2026-08-04

### ホットフィックス

- Windows セッションごとの名前付き mutex を追加し、アプリケーションの二重起動を
  防止しました。
- アプリケーションが既に実行中のときに再起動すると、追加のメインウィンドウを
  作らずにメッセージを表示して終了します。
- 通常終了時と起動失敗時に mutex ハンドルを解放します。

### 検証

- tests/test_review_hardening.py: 11 件のテストが成功。
- 追跡対象の回帰テストスイート全体: 35 件のテストが成功。
- ネイティブ mutex の取得、二重起動拒否、解放後の再取得を確認。
- final_build.py: dist/WindowResizer.exe のビルドに成功。

## 0.01.1 - 2026-07-31

### ホットフィックス

- プロファイル保存をアトミックにし、最後に有効だったバックアップから回復できる
  ようにしました。
- 位置固定またはカーソル制限を解除すると、現在有効な制限も解除されるようにしました。
- マルチモニター環境での Win32 カーソル制限解除を修正しました。
- 初回起動時にシステムテーマを検出し、カスタム選択色で読みやすい文字を保証しました。
- プロファイルに一致するウィンドウがない場合、ステータスバーに適用結果を表示します。
- QApplication の作成前に高 DPI 設定を適用し、ソースアイコンがなくても公式ビルドが
  成功するようにしました。

## 0.01 - 2026-07-31

### 初回リリースの改善

- すべて適用が実行ファイルパスでプロファイルを照合できるよう、ウィンドウ識別情報を
  改善しました。
- テーマの余白による文字切れを防ぐため、プロファイルツールバーのボタンとステータス
  ラベルの高さを増やしました。
- タイトルバーの閉じる操作をシステムトレイへの非表示に変更し、ステータスバーと
  トレイメニューに明示的な終了操作を追加しました。
- ウィンドウからプロファイルを作成した後に新しい行を自動選択し、必要ならすぐ削除
  できるようにしました。
- プロファイルストアからの削除に失敗した理由を隠さず表示するようにしました。
- プロファイル照合条件に実行ファイルの完全パスを追加し、プロセス ID より推奨される
  識別子としました。
- 選択した照合方法に必要な入力だけを有効にし、選択中ウィンドウの実行ファイルパスを
  取得する操作を追加しました。
- プロファイル一覧でパスベースのプロファイルの対象ファイル名と完全パスを表示します。
- 実際のウィンドウを移動またはサイズ変更しない 3 秒間のレイアウトプレビューを追加。
- 新しいウィンドウに対するプロファイル別の自動適用と、メイン画面の検出開始・停止
  コントロールを追加しました。
- 自動検出がプロファイルを適用するとき、各プロファイルで選択した照合方法を維持します。
- 任意のプロファイル位置固定を追加しました。
- プロファイル編集時に既存の詳細設定を維持します。
- 有効な位置固定とカーソル制限を解除できるようにしました。
- アクティブなテーマパレットに基づいてメインウィンドウとプロファイルエディターを
  更新します。
- 交互の表行と標準 Qt 確認ダイアログの視認性を改善しました。
