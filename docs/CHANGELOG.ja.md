このファイルは WindowResizer のユーザーに見える主な変更を記録します。英語版を
リリースノートの正本とし、韓国語・簡体字中国語・日本語版には同じリリース情報を

## 0.02.0-preview.4 - 2026-09-30

WPF（.NET 10）アプリの 4 番目のプレビューで、ソースからビルドします。配布される実行
ファイルは引き続き v0.01.5 です。詳細:
[doc/releases/v0.02.0-preview.4.ja.md](../doc/releases/v0.02.0-preview.4.ja.md)。

### 主な変更

- 設定ページ：テーマ（ライト、ダーク、システムに合わせる）、表示サイズ 75-125%、言語（韓国語、
  英語）、Windows 起動時の自動実行（トレイのみで起動）、ウィンドウのサイズと位置の記憶。変更は
  すぐに保存・反映され、再起動は不要です。スライダーは放したときにサイズを適用し、ドラッグ中は
  横の数字が追従します。
- テーマと表示サイズは v0.01.5 から一度だけ取り込み、別に保存します。Windows のハイコントラストは
  選んだテーマより常に優先されます。

### 検証

- .NET ビルド：警告 0 件、エラー 0 件。テスト 201 件、すべて成功。プロファイルのコピーと一時
  レジストリキーで実行中のアプリで、実際のキー入力と実際のマウスドラッグにより全設定を確認し、
  保存したウィンドウ位置での再オープンまで確認しました。

## 0.02.0-preview.3 - 2026-09-29

WPF（.NET 10）アプリの 3 番目のプレビューで、ソースからビルドします。配布される実行
ファイルは引き続き v0.01.5 です。詳細:
[doc/releases/v0.02.0-preview.3.ja.md](../doc/releases/v0.02.0-preview.3.ja.md)。

### 主な変更

- ショートカットページ: グローバルの「すべて適用」ショートカットと、プロファイルごとに最大
  3 つのショートカット。それぞれ動作を選べます（プロファイルを適用、ロック解除、常に手前の
  切り替え、自動適用の切り替え）。すべてのショートカットが登録結果と、失敗時は理由とともに
  一覧表示されます。各ショートカットは 1 行（修飾キーのチップ、キー一覧、検出ボタン）で、単独で保存され変更のたびに検査されます。登録できない場合は赤い枠、理由、警告ボックスが出ます。
- 新しい「プロファイル > すべてのプロファイルを適用」メニュー。「すべて適用」ショートカットも
  同じ経路を実行します。このショートカットは初回に v0.01.5 から取り込み、別に保存します。
- ロック解除と新しいウィンドウの自動検出はこのプレビューにまだありません。

### 検証

- .NET ビルド: 警告 0 件、エラー 0 件。テスト 159 件、すべて合格。プロファイルのコピーで
  動作中のアプリに実際のキー入力で、すべて適用、適用、常に手前、自動適用のショートカットを
  実行し、競合する組み合わせは理由とともに一覧に表示されました。

## 0.02.0-preview.2 - 2026-09-29

WPF（.NET 10）アプリの 2 番目のプレビューで、ソースからビルドします。配布される実行
ファイルは引き続き v0.01.5 です。詳細:
[doc/releases/v0.02.0-preview.2.ja.md](../doc/releases/v0.02.0-preview.2.ja.md)。

### 主な変更

- オーバーレイボタンが画面に表示されます: クリックまたはドウェルで直前に使っていた
  ウィンドウにプロファイルを適用し、ドラッグ、ロック、右クリックで閉じる、緑/赤の結果点滅が
  あります。
- ボタンはフォーカスを奪いません。クリックしても WindowResizer 自身のウィンドウは前面に
  出ません。
- 非表示スイッチ: オーバーレイボタンを隠したり表示したりする目のボタンで、自分自身は隠れず、
  位置を覚えます。
- 初回起動時に v0.01.5 のオーバーレイ設定を取り込みます。

### 検証

- .NET ビルド: 警告 0 件、エラー 0 件。テスト 112 件、再実行ではすべて合格（フォーカスに
  依存するライブテストは、Windows がフォーカス移動を遮断すると判定不能としてスキップされる
  ことがあります）。実行中のアプリで実際のクリックにより、フォーカス、正確な配置、非表示
  スイッチ、ドラッグを確認しました。

## 0.02.0-preview.1 - 2026-09-27

書き直した WPF（.NET 10）アプリの最初のプレビューで、ソースからビルドします。配布される
実行ファイルは引き続き v0.01.5 です。詳細:
[doc/releases/v0.02.0-preview.1.ja.md](../doc/releases/v0.02.0-preview.1.ja.md)。

### 主な変更

- サイドバー付きメインウィンドウ。ウィンドウとプロファイルが並び、検索でき、Enter は
  再走査してから一致するすべてのウィンドウに適用します。
- ウィンドウを新しいプロファイルとして保存（Ctrl+S、事前入力、プログラム名）、元に戻せる
  位置の上書き（Ctrl+Z）、5 ページのプロファイル編集画面。
- 最大化・最小化されたウィンドウは通常の位置で取得します。
- 保存失敗は元に戻し、読めないプロファイルは残して薄く表示します。
- 閉じるとトレイに隠れ、プログラム終了（サイドバー、Ctrl+Q、トレイ）で終了します。
- オーバーレイ設定ページ、メニュー、トレイ項目。ボタンのウィンドウとショートカット・
  設定・ログのページはこのプレビューにはまだありません。

### 検証

- .NET ビルド: 警告 0 件、エラー 0 件。テスト 102 件合格（実際のウィンドウ、キー入力、
  カーソル制限、前面ウィンドウ追跡のライブ確認を含む）。

## 0.01.5 - 2026-09-25

### 主な変更

- プロファイルごとのオーバーレイボタンを追加しました。クリックまたはホバーで起動でき、全体の表示切替もできます。オーバーレイは対象ウィンドウのフォーカスを奪いません。
- プロファイルのショートカットセットを再起動後も保持し、すべての一致プロファイルを適用するグローバルショートカット設定を追加しました。
- すべて適用は一致する各ウィンドウを試行し、失敗した Win32 呼び出しを成功として表示しないようにしました。
- 移行基盤として .NET 10 WPF ソリューションのスキャフォールドと層境界テストを追加しました。配布 EXE は引き続き PyQt5 アプリです。

### 検証

- 追跡対象の Python 回帰テスト全体: 132 件成功。
- .NET ソリューションのビルド: 警告 0、エラー 0、テスト 8 件成功。
- PyInstaller 単一実行ファイルのビルドに成功。

## 0.01 - 2026-07-31

### 初回リリースの改善

- すべて適用が実行ファイルパスでプロファイルを照合できるよう、ウィンドウ識別情報を
  改善しました。
- テーマの余白による文字切れを防ぐため、プロファイルツールバーのボタンとステータス
  ラベルの高さを増やしました。
- タイトルバーの閉じる操作をシステムトレイへの非表示に変更し、ステータスバーと
  トレイメニューに明示的な終了操作を追加しました。
- ウィンドウからプロファイルを作成した後に新しい行を自動選択し、必要ならすぐ削除
  できるようにしました。
- プロファイルストアからの削除に失敗した理由を隠さず表示するようにしました。
- プロファイル照合条件に実行ファイルの完全パスを追加し、プロセス ID より推奨される
  識別子としました。
- 選択した照合方法に必要な入力だけを有効にし、選択中ウィンドウの実行ファイルパスを
  取得する操作を追加しました。
- プロファイル一覧でパスベースのプロファイルの対象ファイル名と完全パスを表示します。
- 実際のウィンドウを移動またはサイズ変更しない 3 秒間のレイアウトプレビューを追加。
- 新しいウィンドウに対するプロファイル別の自動適用と、メイン画面の検出開始・停止
  コントロールを追加しました。
- 自動検出がプロファイルを適用するとき、各プロファイルで選択した照合方法を維持します。
- 任意のプロファイル位置固定を追加しました。
- プロファイル編集時に既存の詳細設定を維持します。
- 有効な位置固定とカーソル制限を解除できるようにしました。
- アクティブなテーマパレットに基づいてメインウィンドウとプロファイルエディターを
  更新します。
- 交互の表行と標準 Qt 確認ダイアログの視認性を改善しました。
