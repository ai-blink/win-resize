# 변경 기록

[English](CHANGELOG.md) | [한국어](CHANGELOG.ko.md) | [中文](CHANGELOG.zh-CN.md) | [日本語](CHANGELOG.ja.md)

이 문서는 WindowResizer의 주요 사용자 체감 변경을 기록합니다. 영어 문서가 릴리스
노트의 정본이며, 한국어·중국어 간체·일본어 문서는 같은 릴리스 사실을 제공합니다.

## 0.02.0-preview.4 - 2026-09-30

WPF(.NET 10) 앱의 네 번째 미리보기로, 소스에서 빌드합니다. 배포 실행 파일은 계속
v0.01.5 입니다. 자세한 내용:
[doc/releases/v0.02.0-preview.4.ko.md](../doc/releases/v0.02.0-preview.4.ko.md).

### 주요 변경

- 설정 페이지: 테마(밝게, 어둡게, 시스템 따르기), 화면 크기 75-125%, 언어(한국어, 영어),
  Windows 시작 때 자동 실행(트레이로만 시작), 창 크기와 위치 기억. 바꾸는 즉시 저장하고
  적용하며 다시 시작할 필요가 없습니다. 슬라이더는 놓을 때 크기를 적용하고, 끄는 동안에는
  미리보기 견본이 따라갑니다.
- 테마와 화면 크기는 v0.01.5 에서 처음 한 번 가져와 따로 저장합니다. Windows 고대비는
  고른 테마보다 항상 우선합니다.

### 검증

- .NET 빌드: 경고 0개, 오류 0개. 테스트 201개, 모두 통과. 프로필 사본과 임시 레지스트리
  키로 실행 중인 앱에서 실제 키 입력과 실제 마우스 끌기로 모든 설정을 확인했고, 저장한 창
  자리에서 다시 열리는 것까지 확인했습니다.

## 0.02.0-preview.3 - 2026-09-29

WPF(.NET 10) 앱의 세 번째 미리보기로, 소스에서 빌드합니다. 배포 실행 파일은 계속
v0.01.5 입니다. 자세한 내용:
[doc/releases/v0.02.0-preview.3.ko.md](../doc/releases/v0.02.0-preview.3.ko.md).

### 주요 변경

- 단축키 페이지: 전체 적용 단축키와 프로필당 최대 3개 단축키, 각각 동작 선택(프로필 적용,
  잠금 해제, 항상 위 전환, 자동 적용 전환). 모든 단축키가 등록 결과와, 실패하면 이유와 함께
  목록에 보입니다. 단축키는 한 줄(수정키 칩, 키 목록, 감지 버튼)이고 줄마다 저장하며 바뀌는 즉시 검사합니다. 등록할 수 없으면 빨간 테두리, 이유, 경고 상자가 나옵니다.
- 새 프로필 > 전체 프로필 적용 메뉴. 전체 적용 단축키가 같은 경로를 실행합니다. 전체 적용
  단축키는 v0.01.5 에서 처음 한 번 가져와 따로 저장합니다.
- 잠금 해제와 새 창 자동 감지는 이 미리보기에 아직 없습니다.

### 검증

- .NET 빌드: 경고 0개, 오류 0개. 테스트 159개, 모두 통과. 프로필 사본으로 실행 중인
  앱에서 실제 키 입력으로 전체 적용, 적용, 항상 위, 자동 적용 단축키를 실행했고, 충돌하는
  조합은 이유와 함께 목록에 보였습니다.

## 0.02.0-preview.2 - 2026-09-29

WPF(.NET 10) 앱의 두 번째 미리보기로, 소스에서 빌드합니다. 배포 실행 파일은 계속
v0.01.5 입니다. 자세한 내용:
[doc/releases/v0.02.0-preview.2.ko.md](../doc/releases/v0.02.0-preview.2.ko.md).

### 주요 변경

- 오버레이 버튼이 화면에 뜹니다: 클릭이나 드웰로 직전에 쓰던 창에 프로필을 적용하고,
  끌기, 잠금, 우클릭 닫기, 초록/빨강 결과 깜빡임이 있습니다.
- 버튼은 포커스를 가져가지 않습니다. 클릭해도 WindowResizer 자기 창이 올라오지 않습니다.
- 감추기 스위치: 오버레이 버튼을 감췄다 보이는 눈 모양 버튼으로, 자기 자신은 숨지 않고
  위치를 기억합니다.
- v0.01.5 의 오버레이 설정을 처음 한 번 가져옵니다.

### 검증

- .NET 빌드: 경고 0개, 오류 0개. 테스트 112개, 재실행에서 모두 통과(포커스에 기대는 실제 창
  테스트는 Windows 가 포커스 이동을 막으면 판정 불가로 건너뛸 수 있음). 실행 중인 앱에서 실제
  클릭으로 포커스, 정확한 배치, 감추기 스위치, 끌기를 확인했습니다.

## 0.02.0-preview.1 - 2026-09-27

새로 작성한 WPF(.NET 10) 앱의 첫 미리보기로, 소스에서 빌드합니다. 배포 실행 파일은
계속 v0.01.5 입니다. 자세한 내용:
[doc/releases/v0.02.0-preview.1.ko.md](../doc/releases/v0.02.0-preview.1.ko.md).

### 주요 변경

- 사이드바 메인 창. 창 목록과 프로필이 나란히 있고, 검색하며, Enter 는 창 목록을
  새로 연 뒤 맞는 창 전부에 적용합니다.
- 창을 새 프로필로 저장(Ctrl+S, 미리 채움, 프로그램 이름), 되돌리기가 있는 위치
  덮어쓰기(Ctrl+Z), 5페이지 프로필 편집 창.
- 최대화/최소화된 창은 원래 위치로 가져옵니다.
- 저장 실패는 되돌리고, 읽지 못한 프로필은 남겨 흐리게 보입니다.
- 창 닫기는 트레이로 숨기고, 프로그램 종료(사이드바, Ctrl+Q, 트레이)는 끝냅니다.
- 오버레이 설정 페이지, 메뉴, 트레이 항목. 버튼 창과 단축키/설정/로그 페이지는 아직
  이 미리보기에 없습니다.

### 검증

- .NET 빌드: 경고 0개, 오류 0개. 테스트 102개 통과(실제 창, 키 입력, 커서 제한, 전경
  창 추적 라이브 확인 포함).

## 0.01.5 - 2026-09-25

### 주요 변경

- 프로필별 오버레이 버튼을 추가했습니다. 클릭 또는 머무름으로 동작하며 전역 숨김
  스위치를 제공합니다. 오버레이는 대상 창의 포커스를 빼앗지 않습니다.
- 프로필 단축키 세트를 재시작 뒤에도 보존하고, 모든 일치 프로필을 적용하는 전역
  단축키 설정을 추가했습니다.
- 전체 적용이 일치하는 모든 창을 시도하며, 실패한 Win32 호출을 성공으로 표시하지
  않도록 수정했습니다.
- .NET 10 WPF 솔루션 스캐폴드와 계층 경계 테스트를 이전 기반으로 추가했습니다.
  배포 EXE는 계속 PyQt5 앱입니다.

### 검증

- 추적 중인 전체 Python 회귀 테스트: 132개 통과.
- .NET 솔루션 빌드: 경고 0개, 오류 0개, 테스트 8개 통과.
- PyInstaller 단일 EXE 빌드 통과.

## 0.01 - 2026-07-31

### 초기 릴리스 개선

- 전체 적용이 실행 파일 경로 기반 프로필을 매칭할 수 있도록 창 식별 정보를 보완했습니다.
- 프로필 작업 표시줄의 버튼과 상태 라벨 높이를 늘려 테마 패딩에 의한 텍스트 잘림을
  없앴습니다.
- 제목 표시줄의 닫기 동작을 시스템 트레이 숨김으로 바꾸고, 상태 표시줄과 트레이
  메뉴에 명시적인 종료 동작을 추가했습니다.
- 창을 프로필로 추가한 뒤 새 행을 자동 선택해 필요할 때 바로 삭제할 수 있게 했습니다.
- 프로필 삭제가 저장소에서 실패하면 원인을 숨기지 않고 안내하도록 보완했습니다.
- 프로필 매칭에 실행 파일 전체 경로를 추가하고 PID 대신 권장 기본 식별자로
  사용하도록 했습니다.
- 프로필 편집기에서 선택한 매칭 방식에 맞는 입력만 활성화하고, 선택한 창의 실행
  파일 경로를 바로 가져올 수 있게 했습니다.
- 프로필 목록에서 경로 기반 프로필의 대상 파일명과 전체 경로를 확인할 수 있게 했습니다.
- 실제 창을 이동하거나 크기를 바꾸지 않는 3초 배치 미리보기를 추가했습니다.
- 프로필별 새 창 자동 적용과 메인 화면의 감지 시작 및 중지 제어를 추가했습니다.
- 자동 감지가 각 프로필의 선택된 매칭 전략을 그대로 사용하도록 보완했습니다.
- 선택 가능한 프로필별 창 위치 고정 옵션을 추가했습니다.
- 프로필 수정 시 기존 고급 설정이 유지되도록 보완했습니다.
- 활성화된 위치 고정과 마우스 커서 제한을 해제할 수 있도록 했습니다.
- 메인 창과 프로필 편집기를 활성 테마 팔레트에서 갱신하도록 했습니다.
- 짝수 표 행과 기본 Qt 확인 대화상자의 가시성을 개선했습니다.
