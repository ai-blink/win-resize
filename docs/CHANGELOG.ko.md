# 변경 기록

[English](CHANGELOG.md) | [한국어](CHANGELOG.ko.md) | [中文](CHANGELOG.zh-CN.md) | [日本語](CHANGELOG.ja.md)

이 문서는 WindowResizer의 주요 사용자 체감 변경을 기록합니다. 영어 문서가 릴리스
노트의 정본이며, 한국어·중국어 간체·일본어 문서는 같은 릴리스 사실을 제공합니다.

## 0.01.4 - 2026-08-10

### 핫픽스

- 전체 적용이 비동기 창 목록 새로고침을 기다린 뒤 최신 창 목록에 프로필을 적용합니다.
- WindowResizer 실행 뒤 새로 열린 창도 전체 적용 한 번으로 매칭하고 적용합니다.

### 검증

- tests/test_apply_all_profiles.py: 2개 테스트 통과.
- 추적 중인 전체 회귀 테스트: 36개 통과.
- final_build.py: dist/WindowResizer.exe 빌드 성공.

## 0.01.3 - 2026-08-04

### 핫픽스

- Windows 세션별 named mutex를 추가해 앱의 중복 실행을 막았습니다.
- 이미 실행 중인 상태에서 다시 실행하면 추가 메인 창을 만들지 않고 안내 후 종료합니다.
- 정상 종료와 시작 실패 시 mutex 핸들을 해제합니다.

### 검증

- tests/test_review_hardening.py: 11개 테스트 통과.
- 추적 중인 전체 회귀 테스트: 35개 통과.
- native mutex 획득, 중복 거부, 해제 후 재획득을 확인했습니다.
- final_build.py: dist/WindowResizer.exe 빌드 성공.

## 0.01.1 - 2026-07-31

### 핫픽스

- 프로필 저장을 원자적으로 처리하고 마지막 정상 백업에서 복구할 수 있게 했습니다.
- 위치 고정 또는 마우스 커서 제한을 해제할 때 활성 제약도 함께 해제하도록 보완했습니다.
- 다중 모니터 환경에서 Win32 커서 제한을 올바르게 해제하도록 수정했습니다.
- 시스템 테마를 첫 실행부터 감지하고 사용자 지정 선택 색상의 텍스트 대비를 보장했습니다.
- 일치하는 창이 없는 프로필 적용 결과를 상태 표시줄에 표시했습니다.
- 고해상도 DPI 설정을 QApplication 생성 전에 적용하고, 소스 아이콘이 없어도 공식
  빌드가 동작하도록 보완했습니다.

## 0.01 - 2026-07-31

### 초기 릴리스 개선

- 전체 적용이 실행 파일 경로 기반 프로필을 매칭할 수 있도록 창 식별 정보를 보완했습니다.
- 프로필 작업 표시줄의 버튼과 상태 라벨 높이를 늘려 테마 패딩에 의한 텍스트 잘림을
  없앴습니다.
- 제목 표시줄의 닫기 동작을 시스템 트레이 숨김으로 바꾸고, 상태 표시줄과 트레이
  메뉴에 명시적인 종료 동작을 추가했습니다.
- 창을 프로필로 추가한 뒤 새 행을 자동 선택해 필요할 때 바로 삭제할 수 있게 했습니다.
- 프로필 삭제가 저장소에서 실패하면 원인을 숨기지 않고 안내하도록 보완했습니다.
- 프로필 매칭에 실행 파일 전체 경로를 추가하고 PID 대신 권장 기본 식별자로
  사용하도록 했습니다.
- 프로필 편집기에서 선택한 매칭 방식에 맞는 입력만 활성화하고, 선택한 창의 실행
  파일 경로를 바로 가져올 수 있게 했습니다.
- 프로필 목록에서 경로 기반 프로필의 대상 파일명과 전체 경로를 확인할 수 있게 했습니다.
- 실제 창을 이동하거나 크기를 바꾸지 않는 3초 배치 미리보기를 추가했습니다.
- 프로필별 새 창 자동 적용과 메인 화면의 감지 시작 및 중지 제어를 추가했습니다.
- 자동 감지가 각 프로필의 선택된 매칭 전략을 그대로 사용하도록 보완했습니다.
- 선택 가능한 프로필별 창 위치 고정 옵션을 추가했습니다.
- 프로필 수정 시 기존 고급 설정이 유지되도록 보완했습니다.
- 활성화된 위치 고정과 마우스 커서 제한을 해제할 수 있도록 했습니다.
- 메인 창과 프로필 편집기를 활성 테마 팔레트에서 갱신하도록 했습니다.
- 짝수 표 행과 기본 Qt 확인 대화상자의 가시성을 개선했습니다.
