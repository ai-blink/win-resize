# 사용 안내

## 화면 구성

왼쪽 사이드바에 다섯 페이지가 있습니다: 창과 프로필, 오버레이 버튼, 단축키, 설정, 로그와 정보. 메뉴 막대와 트레이
아이콘에서도 같은 동작을 실행할 수 있습니다. 창을 닫으면 앱은 종료되지 않고 트레이에 숨습니다. 완전히 끝내려면
`Ctrl+Q`나 트레이의 `프로그램 종료`를 씁니다.

## 창과 프로필

1. 왼쪽 목록에서 창을 고르고 `Ctrl+S`(새 프로필로 저장)를 눌러 그 창의 위치와 크기를 프로필로 저장합니다.
2. 프로필을 고르고 `적용`(또는 Enter)을 누르면 프로필에 맞는 창 전부에 위치와 크기가 적용됩니다.
3. `위치 덮어쓰기`는 고른 창의 지금 자리로 프로필의 위치와 크기만 바꿉니다. 상태 줄의 `되돌리기`로 되돌릴 수 있습니다.
4. `편집`은 프로필 편집 창을 엽니다(일반, 대상 창, 위치와 크기, 실행 방법, 고급).

대상 창이 관리자 권한으로 실행 중이면 일반 권한 앱에서는 적용되지 않을 수 있습니다.

## 프로필 매칭

편집 창의 `대상 창` 페이지에서 매칭 방식을 고릅니다. `실행 파일 경로`가 가장 안정적입니다(같은 파일명의 다른 프로그램도
구분). 프로세스 이름, 창 제목(포함, 일치, 정규식), 결합(채운 조건을 모두 만족)도 있습니다. `현재 창에서 가져오기`로
창을 골라 값을 채울 수 있습니다.

## 위치 잠금과 마우스 제한 (편집 창의 `고급`)

- **위치 잠금**: 프로필을 적용한 창이 옮겨지거나 크기가 바뀌면 적용했던 자리로 되돌립니다. 최대화나 최소화한 창은
  건드리지 않습니다. 관리자 권한 창처럼 되돌릴 수 없는 창은 시도를 그만두고 상태 줄에 알립니다.
- **마우스 제한**: 그 창이 앞에 있는 동안 마우스를 창 안에 둡니다. 다른 창으로 전환하면 풀리고, 돌아오면 다시
  가둡니다. 프로필 파일의 `constraint_escape_key`(기본 `Escape`)를 누르면 다음 적용까지 풀립니다.
- 잠금과 제한은 프로필을 적용한 창에만 걸립니다. 단축키의 `잠금 해제`(release_profile)나 프로필 편집·삭제로
  풀 수 있고, 앱을 끝내면 모두 풀립니다.

## 새 창 자동 적용

편집 창의 `실행 방법`에서 `자동 적용`을 켜고 저장하면, 앱을 켠 **뒤에** 새로 뜬 창 중 프로필 조건과 맞는 것에
프로필이 자동 적용됩니다. 앱을 켤 때 이미 열려 있던 창은 대상이 아닙니다(`전체 적용`이나 단축키로 적용하세요).
창 하나에 프로필이 여럿 맞으면 가장 구체적인 하나(전체 경로, 제목 일치, 프로세스, 제목 일부 순)만 적용합니다.
적용 지연(`apply_delay`, 기본 2초), 시도 횟수(`max_retries`, 기본 3), 재시도 간격(`retry_delay`, 기본 0.5초)은
프로필 파일의 값을 씁니다. 자동 적용 프로필이 있으면 상태 줄 오른쪽에 `자동 감지 중: 프로필 N개`가 보입니다.

## 오버레이 버튼

오버레이 버튼 페이지에서 `새 버튼`을 누르면 **직전에 쓰던 다른 프로그램 창**의 위치와 크기로 버튼이 만들어집니다.
버튼은 프로필과 따로 자기 이름과 창 위치·크기를 저장하고, 누르면 직전에 쓰던 창을 그 자리로 옮깁니다.

- 우클릭 메뉴: 속성..., 복제, 직전 창의 위치·크기로 갱신, 이 버튼 삭제(갱신과 삭제는 구분선 아래).
- 속성 창: 일반(이름, 버튼 글자), 크기 및 위치(숫자 입력, `화면에서 창 고르기`, `직전 창에서 가져오기`), 동작(클릭 또는
  머무르기, 시간), 외형(모양, 크기, 색, 실제 크기 미리보기).
- `화면에서 창 고르기`는 창 위에 마우스를 올리면 테두리가 나타나고 클릭하면 그 창의 자리를 가져옵니다(Esc나
  오른쪽 클릭은 취소).
- 발동 방식(클릭/머무르기), 감추기, 스위치, 잠금은 오버레이 버튼 페이지에서 정합니다. `모든 버튼 감추기`는 버튼을
  지우지 않고 감춥니다.

## 단축키

단축키 페이지에서 전체 적용 단축키를 정하고, 프로필별 단축키(여러 조합, 동작: 프로필 적용, 자동 적용 전환, 잠금
해제)를 편집합니다. 이미 다른 프로그램이 쓰는 조합은 등록되지 않고 이유가 목록에 보입니다. 항상 위 전환은 앞에 있는
창을 뒤집습니다.

## 설정

테마(시스템 따르기, 밝게, 어둡게. Windows 고대비가 켜져 있으면 항상 그 색), 화면 배율(75%~250%, 슬라이더를 놓으면 적용), 표시 언어(한국어, English),
Windows 시작 때 자동 실행, 창 위치 기억을 정합니다.

## 로그와 정보

상태 줄에 나온 모든 문구와 처리되지 않은 오류가 로그에 쌓입니다(메모리에만 있고 파일로 내보낼 수 있습니다).
정보 탭에는 버전, 실행 파일, 프로필 폴더, 설정 키가 보입니다.

## 알려진 한계

- PyQt5의 프로필 미리보기(3초 테두리)는 아직 없습니다.
- 표시 언어는 한국어와 영어뿐입니다.
- 마우스 제한은 창 바깥 테두리 사각형 전체를 기준으로 합니다.
