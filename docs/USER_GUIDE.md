# 사용 안내

## 창 이동과 크기 조절

1. 메인 창에서 대상 창을 선택합니다.
2. 위치와 크기 입력값을 확인합니다.
3. 적용 동작을 실행해 선택한 창에 반영합니다.

대상 창이 관리자 권한으로 실행 중이면 일반 권한 앱에서 적용되지 않을 수 있습니다.

## 프로필

프로필은 창의 위치와 크기를 저장해 같은 구성을 다시 적용하는 기능입니다.
프로필 편집기의 `창 설정`에서 다음 옵션을 선택할 수 있습니다.

- `창 위치 고정`: 프로필 적용 뒤 사용자가 옮긴 창을 저장된 위치로 되돌립니다.
- 마우스 커서 제한: 커서 동작을 제어하는 별도 옵션입니다.

두 옵션은 독립적입니다. 창 이동을 막고 싶지 않으면 `창 위치 고정`을 끄고 프로필을
저장하세요. 이미 적용된 제약은 다음 적용 시 해제됩니다.

## 안정적인 프로필 매칭

프로필 편집기의 `창 설정`에서 `실행 파일 경로 (권장)`를 선택하면 같은 파일명의
다른 프로그램까지 구분할 수 있습니다. 프로그램을 다시 실행해도 이 경로는 유지되지만
PID는 실행할 때마다 바뀌므로 프로필 매칭에 사용하지 않습니다.

1. 메인 화면에서 대상 창을 선택합니다.
2. 프로필 편집기의 `창 설정`에서 `실행 파일 경로 (권장)`를 선택합니다.
3. `현재 창에서 가져오기`를 눌러 경로를 채운 뒤 저장합니다.

`종합 매칭`을 선택하면 입력한 제목, 프로세스 이름, 실행 파일 경로가 모두 일치해야
프로필이 적용됩니다.

## 프로필 미리보기

프로필 목록에서 프로필을 선택한 뒤 `미리보기`를 누르면 저장된 위치와 크기가
화면 위에 3초 동안 표시됩니다. 이 동작은 실제 창을 이동하거나 크기를 바꾸지
않으므로 적용 전 배치를 확인할 때 사용합니다.

## 새 창 자동 적용

1. 프로필 편집기의 `기본 정보`에서 `새 창 감지 시 자동 적용`을 선택해 저장합니다.
2. 프로필 목록 아래의 `자동 감지 켜기`를 누릅니다.
3. 설정한 제목, 프로세스 또는 실행 파일 경로 조건과 일치하는 새 창이 열리면 저장된 구성이 적용됩니다.

자동 감지는 명시적으로 켠 프로필에만 동작하며 앱을 닫으면 중지됩니다. 버튼의
상태 텍스트에서 감지 중인 프로필 수를 확인할 수 있습니다.

## 창 닫기와 시스템 트레이

제목 표시줄의 닫기 버튼을 누르면 앱은 종료되지 않고 시스템 트레이로 숨겨집니다.
자동 감지처럼 백그라운드에서 계속 필요한 기능은 이 상태에서도 동작합니다.

- 트레이 아이콘을 한 번 또는 두 번 클릭하거나, 오른쪽 클릭 메뉴의 `창 열기`를
  선택하면 메인 창을 다시 표시합니다.
- 앱을 실제로 종료하려면 상태 표시줄의 `프로그램 종료` 버튼이나 트레이 메뉴의
  `프로그램 종료`를 사용합니다.
- 시스템 트레이를 사용할 수 없는 환경에서는 닫기 버튼이 기존처럼 앱을 종료합니다.

## 테마와 가시성

테마를 바꾸면 기본 화면, 프로필 편집기, 표의 짝수 행, 선택 상태, 확인 대화상자에
같은 팔레트가 적용됩니다. 텍스트가 보이지 않으면 다음 순서로 확인합니다.

1. 테마를 다시 선택합니다.
2. 앱을 재시작합니다.
3. 문제가 계속되면 어떤 테마와 어떤 화면인지 함께 기록해 보고합니다.

프로필 삭제 같은 파괴적 동작은 테마가 적용된 확인 대화상자를 표시합니다.
