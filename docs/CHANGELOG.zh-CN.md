## 0.02.0-preview.9 - 2026-09-30

WPF（.NET 10）应用的第九个预览版，从源码构建；分发的可执行文件仍是 v0.01.5。

## 0.02.0-preview.3 - 2026-09-29

WPF（.NET 10）应用的第三个预览版，从源码构建；分发的可执行文件仍是 v0.01.5。

- 快捷键页面：全局“全部应用”快捷键，以及每个配置文件最多三个快捷键，各自选择动作（应用

  v0.01.5 导入一次，并单独保存。

## 0.02.0-preview.2 - 2026-09-29

WPF（.NET 10）应用的第二个预览版，从源码构建；分发的可执行文件仍是 v0.01.5。
详情：[doc/releases/v0.02.0-preview.2.zh-CN.md](../doc/releases/v0.02.0-preview.2.zh-CN.md)。

### 主要变更

- 悬浮按钮现已显示在屏幕上：点击或停留即可把配置文件应用到你刚才使用的窗口；可拖动、锁定、
  右键关闭，并以绿色或红色闪烁显示结果。
- 按钮不会夺取焦点；点击不再把 WindowResizer 自己的窗口提到前面。
- 隐藏开关：一个眼睛按钮，可隐藏和显示所有悬浮按钮，自己不会隐藏，并会记住位置。
- 首次运行时导入 v0.01.5 的悬浮按钮设置。

### 验证

- .NET 构建：0 个警告，0 个错误；112 个测试，重复运行均通过（依赖焦点的实时测试在 Windows
  阻止焦点切换时可能以“无法判定”跳过）；在运行中的应用上用真实点击检查了焦点、准确放置、
  隐藏开关和拖动。

## 0.01.5 - 2026-09-25

### 主要变更

- 新增按配置文件设置的悬浮按钮，支持点击或停留触发，并提供全局隐藏开关。悬浮层不会夺取目标窗口焦点。
- 配置文件快捷键组会在重启后保留，并新增用于应用所有匹配配置文件的全局快捷键设置。
- “全部应用”会尝试每个匹配窗口，并且不再将失败的 Win32 调用显示为成功。
- 新增 .NET 10 WPF 解决方案脚手架和层边界测试，作为迁移基础。发布的 EXE 仍为 PyQt5 应用。

### 验证

- 完整受跟踪 Python 回归测试：132 项通过。
- .NET 解决方案构建：0 个警告、0 个错误，8 项测试通过。
- PyInstaller 单一可执行文件构建通过。

## 0.01.1 - 2026-07-31

### 热修复

- 将配置文件保存改为原子操作，并支持从最后一个有效备份恢复。
- 取消位置锁定或光标限制时，现在也会解除当前生效的限制。
- 修复了多显示器系统上的 Win32 光标限制释放行为。
- 在首次启动时检测系统主题，并确保自定义选中颜色的文本清晰可读。

- 在创建 QApplication 前应用高 DPI 设置，并允许缺少源图标时官方构建仍可成功。

## 0.01 - 2026-07-31

### 初始版本改进

- 改进窗口标识信息，使“全部应用”可按可执行文件路径匹配配置文件。
- 增加配置文件工具栏按钮和状态标签的高度，防止主题内边距导致文本被截断。
- 将标题栏关闭操作改为隐藏到系统托盘，并在状态栏和托盘菜单中提供明确的退出操作。
- 从窗口创建配置文件后自动选择新行，必要时可立即删除。
- 显示配置文件存储删除失败的原因，而不是隐藏该原因。
- 将完整可执行文件路径添加为配置文件匹配条件，并将其作为优先于进程 ID 的推荐标识。
- 仅启用所选匹配策略需要的输入项，并添加提取所选窗口可执行文件路径的操作。
- 在配置文件列表中显示基于路径的配置文件的目标文件名和完整路径。
- 添加三秒布局预览，不会移动或调整实际窗口大小。
- 添加按配置文件对新窗口的自动应用，以及主界面的检测启动和停止控件。
- 自动检测应用配置文件时保留每个配置文件选择的匹配策略。
- 添加可选的配置文件位置锁定。
- 编辑配置文件时保留已有的高级设置。
- 允许解除正在生效的位置锁定和光标限制。
- 根据当前主题调色板刷新主窗口和配置文件编辑器。
- 改善交替表格行和标准 Qt 确认对话框的可见性。
