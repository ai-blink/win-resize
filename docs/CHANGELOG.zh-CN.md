## 0.01.4 - 2026-08-10

### 热修复

- “全部应用”现在会等待异步窗口列表刷新完成，再将配置文件应用到当前窗口列表。
- WindowResizer 启动后新打开的窗口，也可以通过一次“全部应用”完成匹配和更新。

### 验证

- tests/test_apply_all_profiles.py：2 项测试通过。
- 已跟踪的完整回归测试套件：36 项测试通过。
- final_build.py：成功构建 dist/WindowResizer.exe。

## 0.01.3 - 2026-08-04

### 热修复

- 添加按 Windows 会话区分的命名 mutex，防止重复启动应用程序。
- 当应用程序已在运行时再次启动，会显示提示并退出，不会创建额外的主窗口。
- 在正常退出和启动失败时释放 mutex 句柄。

### 验证

- tests/test_review_hardening.py：11 项测试通过。
- 已跟踪的完整回归测试套件：35 项测试通过。
- 已验证原生 mutex 获取、拒绝重复和释放后重新获取。
- final_build.py：成功构建 dist/WindowResizer.exe。

## 0.01.1 - 2026-07-31

### 热修复

- 将配置文件保存改为原子操作，并支持从最后一个有效备份恢复。
- 取消位置锁定或光标限制时，现在也会解除当前生效的限制。
- 修复了多显示器系统上的 Win32 光标限制释放行为。
- 在首次启动时检测系统主题，并确保自定义选中颜色的文本清晰可读。
- 当配置文件没有匹配窗口时，在状态栏显示应用结果。
- 在创建 QApplication 前应用高 DPI 设置，并允许缺少源图标时官方构建仍可成功。

## 0.01 - 2026-07-31

### 初始版本改进

- 改进窗口标识信息，使“全部应用”可按可执行文件路径匹配配置文件。
- 增加配置文件工具栏按钮和状态标签的高度，防止主题内边距导致文本被截断。
- 将标题栏关闭操作改为隐藏到系统托盘，并在状态栏和托盘菜单中提供明确的退出操作。
- 从窗口创建配置文件后自动选择新行，必要时可立即删除。
- 显示配置文件存储删除失败的原因，而不是隐藏该原因。
- 将完整可执行文件路径添加为配置文件匹配条件，并将其作为优先于进程 ID 的推荐标识。
- 仅启用所选匹配策略需要的输入项，并添加提取所选窗口可执行文件路径的操作。
- 在配置文件列表中显示基于路径的配置文件的目标文件名和完整路径。
- 添加三秒布局预览，不会移动或调整实际窗口大小。
- 添加按配置文件对新窗口的自动应用，以及主界面的检测启动和停止控件。
- 自动检测应用配置文件时保留每个配置文件选择的匹配策略。
- 添加可选的配置文件位置锁定。
- 编辑配置文件时保留已有的高级设置。
- 允许解除正在生效的位置锁定和光标限制。
- 根据当前主题调色板刷新主窗口和配置文件编辑器。
- 改善交替表格行和标准 Qt 确认对话框的可见性。
