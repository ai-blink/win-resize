# WindowResizer

[English](README.md) | [한국어](README.ko.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md)

WindowResizer は、アプリケーションのウィンドウを探し、移動やサイズ変更を行い、保存したウィンドウプロファイルを繰り返し適用するための Windows デスクトップアプリケーションです。

現在のリリース: 0.02.0（.NET 10 の WPF で書き直し。以前の PyQt5 アプリは v0.01.5）

## 主な機能

- 実行中のウィンドウを検索し、プロファイルに合う全てのウィンドウへ一度に適用します（ボタン、メニュー、Enter、グローバルショートカット）。
- ウィンドウの位置とサイズをプロファイルとして保存（Ctrl+S）し、ウィンドウからプロファイルの位置を上書き（元に戻せます）し、サイドバー付きの編集画面でプロファイルを編集します。
- 実行ファイルのフルパス、プロセス名、ウィンドウタイトル（含む、完全一致、正規表現）、またはその組み合わせでプロファイルを照合し、同名ファイルのアプリも区別します。
- プロファイルの位置ロック: 動かされたウィンドウを適用時の位置へ戻します。
- プロファイルのウィンドウが前面にある間、マウスをそのウィンドウ内に閉じ込めます（脱出キー対応）。
- アプリ起動後に新しく現れたウィンドウへ、合うプロファイルを自動適用します。
- オーバーレイボタン: 各ボタンが自分のウィンドウ位置とサイズを保存し、押すと直前に使っていたウィンドウをそこへ移動します。プロパティ画面には実寸プレビューがあり、直前のウィンドウや画面上で指し示したウィンドウから位置を取得できます。
- プロファイルごとのグローバルショートカット（複数の組み合わせ、複数の動作）、全適用ショートカット、常に手前の切り替え。
- ライト、ダーク、システム追従のテーマ（Windows ハイコントラスト対応）、75%〜250% のアプリ倍率、韓国語または英語の表示、Windows 起動時の自動実行、ログページ。
- メインウィンドウを閉じるとシステムトレイに常駐し、同じ Windows セッションでは 1 つだけ起動します（2 回目の起動は最初のウィンドウを前面に出します）。

## 0.02.0 にまだ無いもの

- PyQt5 が 3 秒間表示していたプロファイルのプレビュー枠。
- アプリ表示の中国語と日本語（韓国語と英語のみ。ドキュメントは 4 言語です）。
- インストーラーと更新の仕組み。リリースは自己完結型の実行ファイル 1 つです。

## 要件

- Windows 10 または Windows 11、64 ビット。リリースの実行ファイルは .NET ランタイムを内蔵しているため、追加のインストールは不要です。

管理者権限で動作しているウィンドウは、標準権限の WindowResizer では操作できません。必要な場合は WindowResizer も同じ権限レベルで実行してください。

## リリース版の実行

GitHub のリリースから `WindowResizer.exe` をダウンロードして実行します。プロファイルは実行ファイルの隣の `profiles` フォルダーに読み書きされ、設定は `HKCU\Software\WindowResizer\Next` に保存されます。詳細は[インストールと実行ガイド](docs/INSTALLATION.md)を参照してください。

## ソースからのビルド

~~~powershell
dotnet build next\WindowResizer.slnx
dotnet test next\WindowResizer.slnx
powershell -NoProfile -File next\tools\publish.ps1
~~~

最後のコマンドは単一ファイルの実行ファイルを `next\publish\win-x64\` に出力します。ビルドには .NET 10 SDK が必要です。
